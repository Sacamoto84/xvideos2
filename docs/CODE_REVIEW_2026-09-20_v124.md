## Находки

### C1 — Императивный BackHandler в ScreenRedFullScreenFeed и ScreenRedFullScreen. Средняя.

[feature-r/src/main/java/com/client/xvideos/r/ui/fullscreen/ScreenRedFullScreen.kt:171-177, 301-308](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/fullscreen/ScreenRedFullScreen.kt#L171-L177)

В ленточном `ScreenRedFullScreenFeed` и одиночном `ScreenRedFullScreen` использовались безусловные императивные обработчики кнопки «Назад»:
```kotlin
BackHandler {
    if (isCurrentPageZoomed) {
        resetZoomTrigger++
    } else {
        navigator.pop()
    }
}
```
Такой обработчик постоянно зарегистрирован как перехватывающий событие в `OnBackPressedDispatcher`, блокируя предиктивную анимацию возврата Android (Predictive Back) и создавая расхождение со стандартом других видеоплееров (`ScreenX_VideoPlayer`, `ScreenX_LocalVideoPlayer`, `L_FullScreenImage`).

**Решение:**
Переведено на декларативное разделение по условию зума:
```kotlin
BackHandler(enabled = isCurrentPageZoomed) {
    resetZoomTrigger++
}
BackHandler(enabled = !isCurrentPageZoomed) {
    navigator.pop()
}
```
и аналогично для одиночного плеера по условию `isZoomed`.

### C2 — Искажение времени возобновления длинных видео (> 1 часа) и дублирование форматирования. Средняя.

[feature-x/src/main/java/com/client/xvideos/x/screens/videoplayer/ScreenX_VideoPlayerSM.kt:139-144](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/videoplayer/ScreenX_VideoPlayerSM.kt#L139-L144)
[feature-x/src/main/java/com/client/xvideos/x/screens/videoplayer/ScreenX_LocalVideoPlayer.kt:83-88](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/videoplayer/ScreenX_LocalVideoPlayer.kt#L83-L88)

В `ScreenX_VideoPlayerSM` и `ScreenX_LocalVideoPlayer` при формировании текста плашки возобновления (`resumeNoticeText`) вручную вычислялись минуты и секунды по формуле `val minutes = totalSec / 60; val seconds = totalSec % 60; String.format("Возобновлено с %02d:%02d", minutes, seconds)`.
Если длительность видео превышала 1 час (3600 секунд), количество минут не ограничивалось 60 и форматировалось как `Возобновлено с 61:05` вместо каноничного `1:01:05`. Кроме того, этот код дублировался между сетевым и локальным плеерами, игнорируя существующую утилиту `formatTime`.

**Решение:**
1. Оба экрана переведены на вызов переиспользуемой функции `formatTime(totalSec)` из пакета `com.client.xvideos.x.screens.videoplayer.atom`:
   ```kotlin
   resumeNoticeText = "Возобновлено с ${formatTime(totalSec)}"
   ```
2. Для видео длиннее одного часа отображается формат `H:MM:SS`, а для более коротких — `M:SS`.
3. В `X_PlayerBottomBarTest.kt` добавлен модульный тест, проверяющий корректность сборки строки возобновления для обычных и часовых видео.
