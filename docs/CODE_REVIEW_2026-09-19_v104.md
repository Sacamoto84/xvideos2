# Код-ревью: Итерация 125 (2026-09-19)

**Фокус ревью:** `:feature-r` (`SearchTab.kt`, `RedSearchCreatorsTest.kt`), `:feature-l` (`L_FullScreenImage.kt`, `ScreenLAlbumSM.kt`, `AlbumInfoButtonSaveAlbum.kt`), `:app` (`SplashActivity.kt`), `:feature-x` (`readHtmlFromURLWebView.kt`, `DashboardsPaginatedListScreen.kt`, `country.kt`, `ScreenX_VideoPlayerFullScreen.kt`).
Подсистемы: поиск авторов RedGifs и навигация в профиль, иерархия жестов «Назад» в полноэкранном просмотрщике Luscious, обратная связь сохранения альбомов и локализация кнопок, сохранение deep links и параметров запуска в SplashActivity, устранение устаревших API и чистота компиляции.

## 1. Контекст и цели

1. **[UI44] Полноценный UX поиска авторов, навигация в профиль и индикация в `SearchTab.kt` (`:feature-r`)**:
   - Вкладка поиска авторов RedGifs содержала поле ввода `OutlinedTextField` в `bottomBar` без `fillMaxWidth()`, без иконки поиска, кнопки очистки и плейсхолдера; отсутствовала индикация загрузки и сообщения о пустых состояниях.
   - Элементы списка `SearchCreatorItem` не реагировали на нажатия, из-за чего пользователь не мог перейти в профиль найденного автора.
   - *Решение:*
     - Перенести поисковую строку в верхнюю панель экрана с `fillMaxWidth()`, иконкой поиска, кнопкой очистки и плейсхолдером «Поиск авторов...».
     - Добавить реактивный флаг `isLoading` в `ScreenRedExplorerSearchSM` с отображением `LinearProgressIndicator` во время запроса к сети.
     - Сделать карточки авторов `SearchCreatorItem` интерактивными: клик извлекает канонический никнейм (`item.text.removePrefix("@").ifBlank { item.name }`) и открывает `ScreenRedProfile(handle)`.
     - Добавить бейдж верификации автора и форматирование числа подписчиков.
2. **[UI45] Иерархия жестов «Назад» в иммерсивном режиме `L_FullScreenImage` (`:feature-l`)**:
   - В просмотрщике альбомов Luscious при скрытых элементах интерфейса (`isFullScreen == true`) нажатие кнопки «Назад» сразу закрывало экран просмотра альбома.
   - *Решение:*
     - Добавить обработчик `BackHandler(enabled = !isCurrentPageZoomed && isFullScreen) { isFullScreen = false }`.
     - Теперь навигация назад работает по строгой пошаговой иерархии: 1-й шаг сбрасывает зум изображения/видео (если активно), 2-й шаг возвращает скрытые панели управления, 3-й шаг закрывает просмотрщик.
3. **[C44] Обратная связь и локализация сохранения альбома (`:feature-l`)**:
   - В `ScreenLAlbumSM.saveAlbum()` отсутствовала обратная связь: если метаданные альбома ещё не были загружены (`details == null`), клик молча игнорировался; при успехе пользователь не получал подтверждения.
   - В `AlbumInfoButtonSaveAlbum.kt` текст кнопок был жестко зашит на английском языке («Save Album», «Remove Album»).
   - *Решение:*
     - В `saveAlbum()` добавлены уведомления `SnackBar.success("Альбом сохранён")` и `SnackBar.error("Информация об альбоме ещё не загружена")`.
     - В `AlbumInfoButtonSaveAlbum.kt` надписи локализованы на русский язык («Сохранить альбом», «Удалить из сохранённых»).
4. **[C45] Проброс Action, Data и Extras при старте в `SplashActivity` (`:app`)**:
   - После выполнения фоновой инициализации `SplashActivity` запускала `MainActivity` через пустой `Intent(this, MainActivity::class.java)`, теряя переданные системой или внешними приложениями `action`, глубокие ссылки `data` и `extras`.
   - *Решение:* Копировать `action`, `data` и `extras` в интент запуска `MainActivity`.
5. **[A48] Гигиена предупреждений компилятора и удаление Web SQL (`:feature-x`, `:app`)**:
   - В `readHtmlFromURLWebView.kt` удалена устаревшая настройка `databaseEnabled = true` (Web SQL отключен в современных версиях WebView) и подавлено предупреждение `OVERRIDE_DEPRECATION`.
   - В `DashboardsPaginatedListScreen.kt`, `country.kt`, `ScreenX_VideoPlayerFullScreen.kt` и `SplashActivity.kt` добавлены точечные подавления `@Suppress("DEPRECATION")`. Модули `:feature-x` и `:app` компилируются с 0 предупреждений.
6. **[T55] Модульное тестирование (`:feature-r`)**:
   - Разработан тестовый класс `RedSearchCreatorsTest`, проверяющий разбор JSON-ответа `SearchCreatorsResponse`, верификацию авторов, корректность извлечения никнейма без префикса `@` и fallback на отображаемое имя.

## 2. Выявленные замечания и исправления

### [UI44] Поиск авторов RedGifs и навигация в профиль
- **Проблема:** В [SearchTab.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/search/SearchTab.kt) поле ввода находилось внизу экрана без `fillMaxWidth()`, без индикации процесса поиска, а нажатие на карточку автора ничего не открывало.
- **Решение:** Поисковое поле перенесено наверх с полным набором контролов (поиск, очистка, прогрессбар), реализована навигация в [ScreenRedProfile](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/profile/ScreenRedProfile.kt), добавлен бейдж верификации и форматирование подписчиков.
- **Статус:** Исправлено.

### [UI45] Обработка кнопки «Назад» в полноэкранном режиме Luscious
- **Проблема:** В [L_FullScreenImage.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenFullScreen/L_FullScreenImage.kt) при скрытых контролах (`isFullScreen == true`) кнопка «Назад» закрывала просмотр вместо возврата панелей.
- **Решение:** Добавлен `BackHandler(enabled = !isCurrentPageZoomed && isFullScreen) { isFullScreen = false }`.
- **Статус:** Исправлено.

### [C44] Обратная связь сохранения альбома и русская локализация
- **Проблема:** В [ScreenLAlbumSM.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbum/ScreenLAlbumSM.kt) метод `saveAlbum()` не выдавал сообщений об успехе или отсутствии данных. В [AlbumInfoButtonSaveAlbum.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbum/atom/AlbumInfoButtonSaveAlbum.kt) кнопки были на английском языке.
- **Решение:** Добавлены `SnackBar.success` и `SnackBar.error`, кнопки переведены на русский язык.
- **Статус:** Исправлено.

### [C45] Сохранение deep links в SplashActivity
- **Проблема:** В [SplashActivity.kt](file:///g:/xvideos2/app/src/main/java/com/client/xvideos/SplashActivity.kt) при переходе к `MainActivity` отбрасывались `intent.action`, `intent.data` и `intent.extras`.
- **Решение:** Интент `MainActivity` копирует оригинальные `action`, `data` и `extras`.
- **Статус:** Исправлено.

### [A48] Устранение устаревших API и предупреждений компилятора
- **Проблема:** `databaseEnabled` в [readHtmlFromURLWebView.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/feature/net/readHtmlFromURLWebView.kt) создавал предупреждение устаревшего API Web SQL.
- **Решение:** Удален вызов `databaseEnabled`, точечно добавлены `@Suppress("DEPRECATION")` в затронутых компонентах.
- **Статус:** Исправлено.
