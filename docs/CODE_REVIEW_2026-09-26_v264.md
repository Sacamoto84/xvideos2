### Pass 969 (`:feature-x` — `HTML5PlayerConfig.kt`)
- **Finding:** Callers inspecting video stream configurations had to manually check collection and string emptiness for sponsors, uploader name, video title, and thumbnail slide URLs.
- **Fix:** Added `hasSponsors`, `hasUploader`, `hasTitle`, and `hasSlides` computed properties.

---

### Pass 970 (`:feature-x` — `TagsModel.kt`)
- **Finding:** `TagsModel` and `TagsMainUploaderPornstar` lacked collection presence checks and total count calculation, forcing repetitive `tags.isNotEmpty()` or `pornstars.isNotEmpty()` checks.
- **Fix:** Added `hasCount` to `TagsMainUploaderPornstar`, and added `hasMainUploader`, `hasPornstars`, `hasTags`, and `totalCount` to `TagsModel`.

---

### Pass 971 (`:feature-r` — `TagInfo.kt`)
- **Finding:** `TagInfo` only verified `name.isNotBlank()`, lacking a check for whether the tag had associated GIFs/count.
- **Fix:** Added `hasCount: Boolean get() = count > 0L`.

---

### Pass 972 (`:feature-r` — `TagSuggestion.kt`)
- **Finding:** `TagSuggestion` lacked presence checks for GIF count and category type.
- **Fix:** Added `hasGifs: Boolean get() = gifs > 0L` and `hasType: Boolean get() = type.isNotBlank()`.

---

### Pass 973 (`:feature-r` — `TagsResponse.kt`)
- **Finding:** `TagsResponse` callers frequently accessed the primary tag via `.tags.firstOrNull()` and checked total tags count.
- **Fix:** Added `count: Int get() = tags.size` and `firstOrNull: TagInfo? get() = tags.firstOrNull()`.

---

### Pass 974 (`:feature-r` — `SearchCreatorsResponse.kt`)
- **Finding:** `SearchItemCreatorsResponse` callers had to manually fall back from empty `name` to `username`, and manually check for image or follower presence. `SearchCreatorsResponse` lacked direct `size` inspection.
- **Fix:** Added `size: Int` to `SearchCreatorsResponse`; added `displayName`, `hasImage`, and `hasFollowers` to `SearchItemCreatorsResponse`.

---

### Pass 975 (`:feature-r` — `SearchItemNichesResponse.kt`)
- **Finding:** `SearchItemNichesResponse` callers had to inspect thumbnail, tag, and subscriber count presence individually. `SearchNichesShortResponse` lacked `size` and first-page checks.
- **Fix:** Added `size` and `isFirstPage` to `SearchNichesShortResponse`; added `displayName`, `hasThumbnail`, `hasGifs`, `hasSubscribers`, and `hasTags` to `SearchItemNichesResponse`.

---

### Pass 976 (`:feature-r` — `SearchItemTagsResponce.kt`)
- **Finding:** `SearchItemTagsResponse` lacked a check for whether the tag search result contained GIFs.
- **Fix:** Added `hasGifs: Boolean get() = gifs > 0L`.
