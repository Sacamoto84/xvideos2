### C1 · Средняя · Последняя строка секций L растягивает карточки на телефоне

После перехода на `FlowRow` с `weight(1f)` ширина карточки зависит от числа элементов в её строке. `sectionRowFillers` на ширине Compact возвращает ноль. При семи альбомах первые две строки содержат по три карточки, а седьмая занимает всю ширину своей строки. Из-за фиксированной пропорции обложки карточка вырастает и по высоте. Заполнять пустые места взвешенными `Spacer` нужно и при трёх колонках. Вывод проверен по коду и правилам измерения Compose. [Поиск](../feature-l/src/main/java/com/client/xvideos/l/ui/screens/explorer/tab/albumSearch/molecule/AlbumSearchSectionBlock.kt#L69), [лента по тегу](../feature-l/src/main/java/com/client/xvideos/l/ui/screens/albumLandingTag/molecule/LandingTagSectionItem.kt#L65), [топ](../feature-l/src/main/java/com/client/xvideos/l/ui/screens/explorer/tab/albumTopHits/molecule/TopHitsSectionItem.kt#L60), [правило для Compact](../core/src/main/java/com/client/xvideos/common/ui/adaptive/AdaptiveRules.kt#L34), [документация Compose](https://developer.android.com/develop/ui/compose/layouts/flow#item-weights)

### C2 · Средняя · Карточки сохранённых авторов R обрезают текст при крупном системном шрифте

Карточка ограничена высотой 78 dp, а имя, строка с `@username` и счётчики получают по 23 dp. Имя и логин заданы в sp, поэтому при увеличении системного шрифта высота строки текста перестаёт помещаться в отведённые 23 dp. Однострочное ограничение с многоточием помогает по ширине. Для высоты карточки и её строк нужны минимальные размеры с возможностью вырасти по содержимому. Вывод сделан по ограничениям разметки. [Карточка автора](../feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/molecule/CreatorListItem.kt#L92)

### C3 · Низкая · Превью сохранённых изображений N теряют края широких страниц

`NPictureCard` теперь использует рамку `137:200` для всех страниц и по-прежнему масштабирует изображение через `ContentScale.Crop`. Страница формата `16:9`, которая раньше целиком помещалась в карточке по своим пропорциям, теперь показывает около 39% ширины. Это затрудняет поиск нужной страницы по миниатюре в лайках и коллекциях. Единый размер рамки можно сохранить с помощью `ContentScale.Fit` для изображений, которые сильно отличаются от её пропорций. Результат рассчитан по пропорциям рамки и изображения. [Превью изображения](../feature-n/src/main/java/com/client/xvideos/n/ui/atom/NPictureCard.kt#L43)

### C4 · Низкая · Разделитель шапки коллекций R больше не доходит до краёв окна

Отступы по 8 dp перенесены с плиток в `contentPadding` сетки. Они теперь сужают и шапку, поскольку `maxLineSpan` занимает все колонки внутри этих отступов. На вкладке коллекций разделитель становится на 16 dp короче, а заголовок смещается относительно соседних вкладок. Поля плиток следует оставить в области карточек. Вывод проверен по цепочке компоновки. [Отступы сетки](../core/src/main/java/com/client/xvideos/common/collectionDB/ui/CollectionsGrid.kt#L110), [шапка коллекций R](../feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_CollectionTab.kt#L201), [общая шапка вкладок](../core/src/main/java/com/client/xvideos/common/ui/atom/SavedTabHeader.kt#L23)
