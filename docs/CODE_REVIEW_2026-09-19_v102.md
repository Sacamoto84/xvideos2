# Код-ревью: Итерация 123 (2026-09-19)

**Фокус ревью:** `:core` (`DownloadTask.kt`), `:feature-x` (`SavedX_Downloads.kt`), `:feature-r` (`ScreenRedFullScreen.kt`, `RedPooledVideoPlayer.kt`), `:feature-l` (`ScreenLSubscribedAlbumsSM.kt`, `ScreenLServerLikesSM.kt`), `:app` (`WebServerSettingsSection.kt`).
Подсистемы: загрузчик файлов KDownloader, управление локальными загрузками Xvideos, полноэкранный плеер и жесты масштабирования RedGifs, отмена гонок пагинации и pull-to-refresh Luscious, гигиена Compose UI настроек.

## 1. Контекст и цели

1. **[C39] Безопасное разрешение коллизий временных файлов в `DownloadTask` (`:core`)**:
   При запуске новой загрузки, если целевой `.temp` файл уже присутствовал на диске и не был зарегистрирован в БД, производилась попытка `deleteTempFile()`. При неудаче удаления (например, файл занят другим процессом или дескриптор заблокирован) код единожды добавлял суффикс `_2`. Если файл `_2` тоже существовал и не мог быть удалён, происходила запись в чужой/заблокированный файл.
   *Решение:* организован цикл перебора кандидатов `_2.._100` с попыткой удаления и выбором свободного имени файла (с fallback на миллисекундный timestamp), гарантирующий уникальность и безопасность временного пути.
2. **[C40] Защита от фантомных видеозаписей в `SavedX_Downloads` (`:feature-x`)**:
   В методе `loadFromDisk()` множество `videoIds` корректно наполнялось идентификаторами существующих и непустых `.mp4` файлов. Однако список `_list.value` строился по всем найденным `.info`-файлам без проверки существования самого видео. В результате, если `.mp4` был удалён пользователем, системой очистки или повреждён, в UI продолжал отображаться ролик, попытка запуска которого в `ScreenX_LocalVideoPlayer` приводила к ошибке.
   *Решение:* добавить строгую фильтрацию `.filter { it.id in videoIds }` при формировании результирующего списка сохранённых видео.
3. **[UI41] Обработка кнопки «Назад» при активном увеличении кадра в `ScreenRedFullScreen` (`:feature-r`)**:
   При зумировании видео (double-tap или pinch-to-zoom) в полноэкранном плеере `userScrollEnabled` отключается, чтобы жест панорамирования не перелистывал ролики. Однако при нажатии системной кнопки «Назад» или жеста назад экран немедленно закрывался с потерей позиции воспроизведения, вместо плавного сброса масштаба к 1.0x. В одиночном режиме (`RedFullScreenSingle`) отслеживание зума вовсе отсутствовало.
   *Решение:* добавить `resetZoomTrigger` в `RedPooledVideoPlayer` и подключить `BackHandler(enabled = isZoomed)` в `RedFullScreenFeed` и `RedFullScreenSingle`.
4. **[T51] Отмена гонок пагинации и pull-to-refresh в `ScreenLSubscribedAlbumsSM` и `ScreenLServerLikesSM` (`:feature-l`)**:
   При вызове `refresh()` во время выполнения `loadNextPage()` сетевой запрос пагинации не отменялся. Ответ устаревшей страницы мог прийти после завершения рефреша, приводя к подмешиванию элементов старой сессии, рассинхронизации `currentPage` и некорректным границам списка.
   *Решение:* сохранять `loadJob: Job?`, отменять его при `refresh()` и `loadInitial()`, сбрасывать `_isLoading.value = false` при рефреше и блокировать `loadNextPage()` при наличии ошибки.
5. **[UI42] Очистка неиспользуемого контекста и подавление deprecation в `WebServerSettingsSection` (`:app`)**:
   В `WebServerConnectionCard` объявленная переменная `val context = LocalContext.current` не использовалась. Для `LocalClipboardManager` добавлено явное подавление `@Suppress("DEPRECATION")` с фиксацией API до завершения общепроектного перехода на корутинный Clipboard.
6. **[T52] Модульное тестирование**:
   - Тест на фильтрацию сиротских `.info` файлов в `SavedX_DownloadsTest`.
   - Тест на генерацию неколлидирующих временных файлов в `KDownloaderQueueTest`.
   - Интеграционные тесты отмены гонок пагинации в `LusciousPaginationRaceTest`.

## 2. Выявленные замечания и исправления

### [C39] Разрешение коллизий временных файлов в DownloadTask
- **Проблема:** В [DownloadTask.kt](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/kdownloader/internal/DownloadTask.kt) при неудаче `deleteTempFile()` генерировался единственный кандидат `${file.nameWithoutExtension}_2.${file.extension}` без проверки на его существование и возможность удаления.
- **Решение:** Перебор кандидатов в цикле `2..100` с проверкой `!candidate.exists() || candidate.delete()` и fallback на отметку времени `System.currentTimeMillis()`.
- **Статус:** Исправлено.

### [C40] Фантомные записи в списке скачанного X
- **Проблема:** В [SavedX_Downloads.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/feature/saved/SavedX_Downloads.kt) `_list.value` формировался из всех `.info` файлов на диске без проверки наличия самого видеофайла в `videoIds`.
- **Решение:** Добавлена фильтрация `infos.mapNotNull { ... }.filter { it.id in videoIds }`.
- **Статус:** Исправлено.

### [UI41] Навигация назад при масштабировании видео RedGifs
- **Проблема:** В [ScreenRedFullScreen.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/fullscreen/ScreenRedFullScreen.kt) при увеличенном масштабе кадра жест назад приводил к выходу из плеера вместо возврата к 1.0x.
- **Решение:** В [RedPooledVideoPlayer.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/video/RedPooledVideoPlayer.kt) добавлен параметр `resetZoomTrigger`, плавно возвращающий масштаб к `1.0f`. В `RedFullScreenFeed` и `RedFullScreenSingle` добавлен `BackHandler(enabled = isZoomed)`.
- **Статус:** Исправлено.

### [T51] Гонка пагинации и pull-to-refresh в Luscious
- **Проблема:** В [ScreenLSubscribedAlbumsSM.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/explorer/tab/saved/subscribedAlbums/ScreenLSubscribedAlbumsSM.kt) и [ScreenLServerLikesSM.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/explorer/tab/saved/serverLikes/ScreenLServerLikesSM.kt) параллельный вызов `refresh()` не отменял фоновую подгрузку следующей страницы.
- **Решение:** Добавлен `loadJob: Job?`, прерывающий предыдущую загрузку при обновлении списка, и сброс флага `_isLoading`.
- **Статус:** Исправлено.

### [UI42] Очистка неиспользуемого контекста в WebServerSettingsSection
- **Проблема:** В [WebServerSettingsSection.kt](file:///g:/xvideos2/app/src/main/java/com/client/xvideos/screenSettings/section/WebServerSettingsSection.kt) `LocalContext.current` вызывался в `WebServerConnectionCard`, но не использовался.
- **Решение:** Удален неиспользуемый контекст, добавлено подавление deprecation для `LocalClipboardManager`.
- **Статус:** Исправлено.
