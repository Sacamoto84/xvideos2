## Summary of Passes (825–832)

### Pass 825 — `:feature-l` (`PicsDetailsMedia.kt`)
- **Finding:** `PicsDetails.lThumbnailImageUrlsBySize()` created a sequence and performed sorting even when `thumbnails` was null or empty. Furthermore, it called `.toList().distinct()`, which allocated an intermediate list before feeding into a set.
- **Fix:** Added `val thumbs = thumbnails; if (thumbs.isNullOrEmpty()) return emptyList()` at entry, and changed the sequence chain to `.mapNotNull { it.url }.distinct().toList()`, eliminating the intermediate list allocation.

### Pass 826 — `:feature-l` (`PicsDetailsMedia.kt`)
- **Finding:** In `isAnimatedMedia()`, `orig.substringBefore('?').substringBefore('#')` was called once manually and then a second time inside `orig.isLVideoFileUrl()`. The same duplicate URL stripping occurred inside the `thumbnails.any` predicate.
- **Fix:** Extracted `isLVideoFilePath()` extension matching raw paths and delegated `isLVideoFileUrl()` to it, ensuring URL query parameters are stripped at most once per candidate. Added early exit `if (thumbs.isNullOrEmpty()) return false`.

### Pass 827 — `:feature-x` (`parserScreenTags.kt`)
- **Finding:** In `parseLastPage(document)`, `pagination.getElementsByTag("a").fold(1) { ... }` allocated an accumulator lambda for every pagination link. In `parseTagItemVideo`, `href.isBlank()` re-scanned whitespace on already-trimmed strings.
- **Fix:** Replaced `fold` with a direct primitive `var maxPage = 1; for (el in ...)` loop without lambdas, and replaced `href.isBlank()` with `href.isEmpty()`.

### Pass 828 — `:feature-r` (`RedApi_Explorer.kt`)
- **Finding:** `getExplorerNiches(count, page)` passed unbounded arguments directly to the RedGifs `/v2/niches` endpoint.
- **Fix:** Added parameter boundaries `page.coerceAtLeast(1)` and `count.coerceIn(1, 100)` preventing invalid query parameters.

### Pass 829 — `:core` (`toPrettyCount.kt`)
- **Finding:** In `toPrettyCount()`, `toPrettyCount2()`, `toPrettyCount3()`, and `toPrettyCountInt()`, passing `0L` executed absolute value logic, branch comparisons, and `Long.toString()`.
- **Fix:** Added fast-path `if (this == 0L) return "0"` returning the string literal immediately.

### Pass 830 — `:core` (`getFolderSize.kt`)
- **Finding:** `getFolderSize(dir: File)` initiated a recursive `dir.walkTopDown()` sequence walker even when the directory contained no files or subdirectories.
- **Fix:** Added `val files = dir.listFiles(); if (files.isNullOrEmpty()) return 0L` to fast-return 0L without walker allocations.

### Pass 831 — `:feature-r` (`URL1.kt`)
- **Finding:** `URL1.sanitize()` allocated a new copy or checked fields on empty instances.
- **Fix:** Introduced `private val EMPTY_URL1 = URL1()` and added `if (this == EMPTY_URL1) return this`.

### Pass 832 — `:feature-x` (`getSearchResults.kt`)
- **Finding:** `getSearchResults(query: String)` called `query.isBlank()` followed by `query.trim()`, and unconditionally executed `.replace("+", "%20")` even when no plus characters were present in the URL-encoded string.
- **Fix:** Trimmed query once (`val trimmed = query.trim(); if (trimmed.isEmpty()) return null`) and only executed `replace` when `rawEncoded.contains('+')`.
