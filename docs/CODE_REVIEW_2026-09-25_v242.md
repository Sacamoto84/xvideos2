## Summary of Passes (793–800)

### Pass 793 — `:feature-r` (`RedApi.kt`)
- **Finding:** `searchNichesShort(text: String)` fired network requests to `/v2/niches/search?query=` on blank or whitespace-only inputs. `getTagSuggestions(query: String)` did not check for an empty string input.
- **Fix:** Added `val trimmed = text.trim(); if (trimmed.isEmpty()) return Result.success(emptyList())` in `searchNichesShort`, and `if (query.isEmpty()) return Result.success(emptyList())` in `getTagSuggestions`, preventing wasteful network requests.

### Pass 794 — `:feature-r` (`ApiClient.kt`)
- **Finding:** In `request` and `requestText` overloads, `params.forEach` and `for ((key, value) in params)` executed loop and iterator setups even when no query parameters were passed (`params.isEmpty()`).
- **Fix:** Guarded parameter bindings with `if (params.isNotEmpty())`, skipping iterator creation on default/empty parameter calls.

### Pass 795 — `:feature-x` (`parserListVideo.kt`)
- **Finding:** `extractViews(metadata: String?)` iterated over all regex matches, repeatedly trimming candidates and updating `lastToken` in a loop.
- **Fix:** Replaced the loop with `VIEWS_TOKEN_REGEX.findAll(metadata).lastOrNull()?.value?.trim()`, evaluating and trimming only the final token.

### Pass 796 — `:core` (`toMinSec.kt`)
- **Finding:** `Float.toMinSec()` called `this.toDouble().toMinSec()`, boxing the float into a `Double` object. Additionally, values formatting to zero seconds still evaluated modulo and string comparisons.
- **Fix:** Implemented `Float.toMinSec()` directly without conversion to `Double`, and added an early return `if (totalSec <= 0) return "00:00"` to both `Double` and `Float` extensions.

### Pass 797 — `:core` (`capitalizeEachWord.kt`)
- **Finding:** `String.capitalizeEachWord()` unconditionally allocated a `StringBuilder`, converted the whole string to lowercase, and iterated through characters even for single-character strings.
- **Fix:** Added an early exit `if (length == 1) return uppercase(Locale.getDefault())`.

### Pass 798 — `:core` (`FileDB.kt`)
- **Finding:** In `FileDB.refresh()`, `files.mapNotNull { ... }` dynamically grew its internal array and allocated an empty list if `files.isEmpty()`.
- **Fix:** Pre-sized `ArrayList<T>(files.size)` and returned `emptyList()` immediately when `files.isEmpty()`, eliminating dynamic array resizes during cache refresh.

### Pass 799 — `:feature-l` (`LandingPageAlbumSearch.kt` & `LandingPageAlbumTag.kt`)
- **Finding:** If the Luscious server responded with an empty body (0 bytes or whitespace), `LJson.parseToJsonElement(rawJson)` threw an `Unexpected EOF` serialization exception with a confusing trace.
- **Fix:** Added `if (rawJson.isBlank())` checks returning an informative `Result.failure(IllegalStateException(...))` before passing to the JSON parser.

### Pass 800 — `:feature-r` (`DownloadRed.kt`)
- **Finding:** `DownloadRed.delete()` checked `files == null || files.isEmpty()`.
- **Fix:** Replaced with idiomatic Kotlin `files.isNullOrEmpty()`.
