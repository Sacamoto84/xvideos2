# Код-ревью: Итерация 128 (2026-09-19)

**Фокус ревью:** `:feature-x` (`ScreenXDashBoards.kt`, `ScreenTags.kt`, `ScreenFavorites.kt`, `ScreenTagsSerializationTest.kt`), `:feature-r` (`SearchTab.kt`, `SearchTabCreatorItemTest.kt`), `:app` (`AppSettingsScreen.kt`, `HapticDemoScreen.kt`, `AppSettingsScreenSerializationTest.kt`).
Подсистемы: возвраты по стеку табов и жестам «Назад» в дашбордах X, детерминированные ключи и `BackHandler` в тегах и избранном, очистка поискового запроса по жесту «Назад» и человекочитаемое форматирование подписчиков в RedGifs, навигация «Назад» на главном экране настроек и демо Haptic Feedback, сохраняемость экранов Voyager в saved state.

## 1. Контекст и цели

1. **[UI52] Возврат из под-табов сохраненного в ленту дашбордов (`:feature-x`)**:
   - В `ScreenXDashBoards.kt` при переходе пользователя во второстепенные табы раздела `Savable` (Избранное, Сохраненное, История) нажатие кнопки «Назад» закрывало экран/приложение целиком, вместо возврата к основному фиду дашбордов.
   - *Решение:*
     - Добавить `BackHandler(enabled = vm.mainTab != 0) { vm.mainTab = 0 }`.
     - Задать детерминированный ключ `override val key: ScreenKey = "ScreenXDashBoards"` вместо недетерминированного `uniqueScreenKey`.
2. **[UI53] Детерминированные ключи и `BackHandler` в `ScreenTags` и `ScreenFavorites` (`:feature-x`)**:
   - `ScreenTags` создавал новый случайный UUID при каждом создании (`uniqueScreenKey`), что ломало дедупликацию и сохранность в стеке экранов Voyager. Кроме того, отсутствовал явный `BackHandler`.
   - `ScreenFavorites` также использовал случайный `uniqueScreenKey`.
   - *Решение:*
     - В `ScreenTags` установить `override val key: ScreenKey = "ScreenTags:$tag"` и добавить `BackHandler { navigator.pop() }`.
     - В `ScreenFavorites` установить `override val key: ScreenKey = "ScreenFavorites"`.
3. **[UI54] Очистка поиска по жесту «Назад» и форматирование подписчиков в `SearchTab.kt` (`:feature-r`)**:
   - В табе поиска авторов `SearchTab.kt` при заполненном поле ввода нажатие «Назад» уводило с экрана или закрывало таб вместо естественной очистки строки поиска.
   - Число подписчиков автора выводилось в сыром виде (`12512` вместо `12.5K`).
   - Ключ экрана был недетерминированным `uniqueScreenKey` у singleton `object SearchTab`.
   - *Решение:*
     - Задать стабильный ключ `override val key: ScreenKey = "RedSearchTab"`.
     - Добавить `BackHandler(enabled = searchText.isNotEmpty()) { onSearchTextChange("") }`.
     - Форматировать счетчик с помощью `item.followers.toPrettyCount()`.
4. **[UI55] Навигация «Назад» и стабильные ключи в `AppSettingsScreen` и `HapticDemoScreen` (`:app`)**:
   - В `AppSettingsScreen.kt` обработчик `BackHandler` был активен только на подстраницах (`enabled = currentPage != SettingsPage.Main`), из-за чего на главной странице настроек системный жест возврата не вызывал `closeCurrentPage()`/`onBack()`.
   - В `HapticDemoScreen.kt` отсутствовал `BackHandler`.
   - Оба singleton-экрана использовали случайный `uniqueScreenKey`.
   - *Решение:*
     - В `AppSettingsScreen` назначить ключ `"AppSettingsScreen"` и сделать `BackHandler { closeCurrentPage() }`.
     - В `HapticDemoScreen` назначить ключ `"HapticDemoScreen"` и добавить `BackHandler { navigator.pop() }`.
5. **[T58] Модульное тестирование сохранности экранов Voyager в saved state**:
   - Добавлен `ScreenTagsSerializationTest` (`:feature-x`): проверка Java-сериализации `ScreenTags`, `ScreenFavorites` и `ScreenXDashBoards`.
   - Добавлен `SearchTabCreatorItemTest` (`:feature-r`): проверка сериализации `SearchTab`, парсинга хэндлов авторов и форматирования `toPrettyCount()`.
   - Добавлен `AppSettingsScreenSerializationTest` (`:app`): проверка сериализации `AppSettingsScreen`, `HapticDemoScreen` и `MenuScreen`.

## 2. Выявленные замечания и исправления

### [UI52] Возврат из под-табов сохраненного в дашборды X
- **Проблема:** В [ScreenXDashBoards.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/ScreenXDashBoards.kt) при нахождении во вкладках `Savable` жест «Назад» приводил к выходу из приложения вместо возврата к ленте видео.
- **Решение:** Подключен `BackHandler(enabled = vm.mainTab != 0) { vm.mainTab = 0 }`, задан стабильный `key`.
- **Статус:** Исправлено.

### [UI53] Стабильные ключи экранов и BackHandler в ScreenTags и ScreenFavorites
- **Проблема:** В [ScreenTags.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/tags/ScreenTags.kt) и [ScreenFavorites.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/favorites/ScreenFavorites.kt) случайные `uniqueScreenKey` нарушали целостность стека навигации при сохранении состояния Activity. В `ScreenTags` отсутствовал `BackHandler`.
- **Решение:** Ключи зафиксированы (`ScreenTags:$tag`, `ScreenFavorites`), добавлен `BackHandler`.
- **Статус:** Исправлено.

### [UI54] Очистка поиска по жесту «Назад» и красивый счетчик подписчиков в RedGifs
- **Проблема:** В [SearchTab.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/search/SearchTab.kt) введенный текст не очищался при жесте «Назад», а счетчик подписчиков отображался без сокращений тысяч и миллионов.
- **Решение:** Добавлен `BackHandler(enabled = searchText.isNotEmpty())`, применен `toPrettyCount()`, зафиксирован ключ `"RedSearchTab"`.
- **Статус:** Исправлено.

### [UI55] Навигация «Назад» и ключи в AppSettingsScreen и HapticDemoScreen
- **Проблема:** В [AppSettingsScreen.kt](file:///g:/xvideos2/app/src/main/java/com/client/xvideos/screenSettings/AppSettingsScreen.kt) на главной странице настроек не перехватывался `BackHandler`, в [HapticDemoScreen.kt](file:///g:/xvideos2/app/src/main/java/com/client/xvideos/HapticDemoScreen.kt) отсутствовал `BackHandler`.
- **Решение:** Добавлены `BackHandler` для корректного закрытия страниц, установлены стабильные ключи экранов.
- **Статус:** Исправлено.

### [T58] Тестирование сериализации навигационных экранов
- **Проблема:** Отсутствовали тесты Java-сериализации экранов настроек, тегов и поиска в saved state.
- **Решение:** Реализованы `ScreenTagsSerializationTest`, `SearchTabCreatorItemTest` и `AppSettingsScreenSerializationTest`.
- **Статус:** Исправлено.
