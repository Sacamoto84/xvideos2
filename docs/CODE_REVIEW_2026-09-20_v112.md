# Код-ревью: Итерация 133 (2026-09-20)

**Фокус ревью:** Иерархическая навигация и предотвращение случайного выхода в `BackupSettingsSection` (защита от выхода при активных операциях создания/восстановления, закрытие диалогов паролей и возврат из режима RESTORE в CREATE), интеграция естественного пошагового `onBackspace` и сброса вычислений `onClear` по нажатию кнопки «Назад» в камуфляжном калькуляторе `CalculatorScreen` с исправлением `isAllClear` для состояний ошибок и тестами в `CalculatorStateTest`, внедрение fast-path отсечения пустых и пробельных запросов авторов в `RedApi_Search.searchCreatorsShort` с тестами в `RedSearchCreatorsTest`, защита утилиты форматирования длительности `toMinSec` от бесконечных значений (`isInfinite`) с фиксацией `Locale.US` и тестами в `FormattingUtilsTest`.

## 1. Контекст и цели

1. **[NAV01] Иерархическая навигация и закрытие диалогов в `BackupSettingsSection` (`:app`)**:
   - В `BackupSettingsSection.kt` отсутствовал локальный `BackHandler`. При открытых диалогах ввода паролей (`showCreatePasswordDialog`, `showRestorePasswordDialog`) или нахождении на вкладке восстановления бэкапа (`screen == BackupFlowScreen.RESTORE`), системное нажатие «Назад» перехватывалось родительским `AppSettingsScreen`, мгновенно сбрасывая страницу настроек на главную (`SettingsPage.Main`). Кроме того, при длительной фоновой операции создания/восстановления архива (`isWorking == true`) случайное нажатие «Назад» могло вызвать дезориентацию пользователя.
   - *Решение:*
     - Внедрён локальный `BackHandler(enabled = isWorking || showCreatePasswordDialog || showRestorePasswordDialog || screen == BackupFlowScreen.RESTORE)`.
     - При активной операции (`isWorking`) выводится предупреждение `SnackBar.info("Пожалуйста, дождитесь окончания операции")`.
     - При открытых диалогах создания/восстановления сначала скрывается соответствующий диалог и очищаются временные состояния ошибок/URI.
     - В режиме `BackupFlowScreen.RESTORE` нажатие «Назад» возвращает пользователя в корневой режим `BackupFlowScreen.CREATE`.
     - Добавлены аннотации `@Suppress("LongMethod", "CyclomaticComplexMethod")`.

2. **[NAV02] Пошаговый Backspace и сброс вычислений по кнопке «Назад» в `CalculatorScreen` (`:app`)**:
   - В `CalculatorScreen.kt` обработчик `BackHandler` безусловно вызывал `onBack()`, что при случайном касании кнопки возврата во время набора PIN-кода или вычислений приводило к немедленному закрытию калькулятора.
   - В `CalculatorState.kt` геттер `isAllClear` ошибочно возвращал `true` при отображении ошибки `ERROR_TEXT`, если `isNewEntry == true`.
   - *Решение:*
     - В `CalculatorState.kt` свойство `isAllClear` дополнено условием `displayValue != ERROR_TEXT`.
     - В `CalculatorScreen.kt` настроен многоуровневый `BackHandler`:
       - При наличии ошибки (`displayValue == ERROR_TEXT`) или наборе цифр (`!state.isNewEntry && state.displayValue != "0"`) выполняется `state.onBackspace(haptic)`.
       - При наличии незавершённых операций или результатов (`!state.isAllClear`) выполняется `state.onClear(haptic)` (двухфазный сброс: сначала текущий ввод до 0 в режиме "C", затем полный сброс до All Clear в режиме "AC").
       - При полностью чистом состоянии (`state.isAllClear && state.displayValue == "0"`) вызывается `onBack()`.
     - В `CalculatorStateTest.kt` добавлены модульные тесты для пошагового `onBackspace`, сброса ошибки и двухфазного `onClear`.

3. **[NET25] Fast-path отсечение пустых и пробельных запросов авторов в `RedApi_Search` (`:feature-r`)**:
   - В `RedApi_Search.kt` метод `searchCreatorsShort(text: String)` отправлял сетевой запрос `/v2/creators/suggest?query={text}` даже для пустых строк или строк из одних пробелов (`""`, `"   "`). Это создавало лишний сетевой трафик и нагрузку на API при стирании поискового запроса в `SearchTab`.
   - *Решение:*
     - Добавлена проверка `val trimmed = text.trim()`; если `trimmed.isEmpty()`, метод немедленно возвращает `Result.success(SearchCreatorsResponse())` без сетевого обращения.
     - В параметр `Route` передаётся нормализованная строка `trimmed`.
     - В `RedSearchCreatorsTest.kt` добавлен модульный тест `searchCreatorsShort returns empty response immediately for blank or empty text`.

4. **[C23] Защита утилиты форматирования времени `toMinSec` от бесконечности (`:core`)**:
   - В `core/.../util/toMinSec.kt` метод `Double.toMinSec()` проверял `isNaN()` и `<= 0.0`, но не фильтровал `isInfinite()`. Положительная бесконечность превышала `Int.MAX_VALUE` и форматировалась в артефакт `"35791394:07"`. Также использовалась системная локаль по умолчанию вместо явной `Locale.US`.
   - *Решение:*
     - Добавлена проверка `this.isInfinite()`, возвращающая `"00:00"`.
     - Форматирование переведено на `String.format(Locale.US, "%02d:%02d", minutes, seconds)`.
     - В `FormattingUtilsTest.kt` добавлены проверки для `Double.POSITIVE_INFINITY`, `Double.NEGATIVE_INFINITY` и `Float.POSITIVE_INFINITY`.

### [NAV01] Иерархическая навигация и защита от сброса в BackupSettingsSection

- **Решение:** Добавлен специализированный `BackHandler`, закрывающий диалоги, предупреждающий во время операций и возвращающий из режима восстановления в режим создания.

В [CalculatorState.kt](file:///g:/xvideos2/app/src/main/java/com/client/xvideos/calculator/CalculatorState.kt) состояние ошибки `ERROR_TEXT` некорректно определялось как `isAllClear`.
- **Решение:** Исправлен `isAllClear`, в `CalculatorScreen` внедрён многоуровневый `BackHandler` (посимвольный `onBackspace` -> `onClear` -> выход). Написаны тесты в [CalculatorStateTest.kt](file:///g:/xvideos2/app/src/test/java/com/client/xvideos/calculator/CalculatorStateTest.kt).

### [NET25] Fast-path отсечение пустых запросов подсказок креаторов в RedApi_Search
- **Проблема:** В [RedApi_Search.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/network/api/RedApi_Search.kt) пустые и пробельные строки отправлялись на сервер RedGifs.
- **Решение:** Внедрён мгновенный возврат `Result.success(SearchCreatorsResponse())` для пустых/пробельных строк. Написан тест в [RedSearchCreatorsTest.kt](file:///g:/xvideos2/feature-r/src/test/java/com/client/xvideos/r/network/api/RedSearchCreatorsTest.kt).
