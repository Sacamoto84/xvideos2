## Находки

### C1 — Неограниченный прогресс скачивания в DownloadTask. Средняя.

[core/src/main/java/com/client/xvideos/common/kdownloader/internal/DownloadTask.kt:304-307](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/kdownloader/internal/DownloadTask.kt#L304-L307)

В цикле чтения данных `DownloadTask` расчёт прогресса производился без ограничения диапазона:
```kotlin
progress = ((req.downloadedBytes * 100) / totalBytes).toInt()
```
Если сервер передавал некорректный заголовок `Content-Length`, отдавал сжатый ответ (gzip) или происходила докачка с избыточным количеством байт, значение прогресса превышало 100% (например 105%), вызывая артефакты в индикаторах UI или исключения при использовании в компонентах со строгим контрактом `0..100`.

**Решение:**
1. Расчёт переведён на явный `Long`-литерал `100L` и ограничен допустимым диапазоном `coerceIn(0, 100)` (в паритете с `MediaDownloadWorker`):
   ```kotlin
   progress = ((req.downloadedBytes * 100L) / totalBytes).toInt().coerceIn(0, 100)
   ```
2. В `KDownloaderQueueTest.kt` добавлен модульный тест, проверяющий граничные случаи расчёта прогресса: превышение размера, отрицательные значения и неопределённый `totalBytes`.

### C2 — Риск отрицательной длительности видео в RedPooledVideoPlayer. Средняя.

[feature-r/src/main/java/com/client/xvideos/r/ui/video/RedPooledVideoPlayer.kt:200-201](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/video/RedPooledVideoPlayer.kt#L200-L201)

В цикле таймера `RedPooledVideoPlayer` длительность вычислялась как `val durationMs = exo.duration.takeIf { it != C.TIME_UNSET } ?: 0L`.
В режимах буферизации, инициализации или при прямых трансляциях `exo.duration` может возвращать отрицательные значения, отличные от `C.TIME_UNSET`, что приводило к отрицательному значению `duration`, передаваемому в UI и коллбеки.

**Решение:**
Длительность валидируется на строго положительное значение и ограничивается неотрицательным нулём:
```kotlin
val durationMs = exo.duration.takeIf { it != C.TIME_UNSET && it > 0L } ?: 0L
val duration = (durationMs / 1000).toInt().coerceAtLeast(0)
```
