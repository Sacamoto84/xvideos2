## Summary of Passes

### Pass 713 (`:core` — `getFolderSize.kt`)
- Replaced recursive `File.listFiles()` implementation (which allocated arrays of `File[]` at every directory depth and risked `StackOverflowError` on deeply nested trees) with non-recursive, stack-safe `dir.walkTopDown().forEach { if (it.isFile) size += it.length() }`.
- Added immediate fast-return check `if (!dir.exists() || !dir.isDirectory) return 0L` to prevent filesystem traversal on missing or non-directory paths.

### Pass 714 (`:feature-x` — `parseHTML5Player.kt`)
- Precompiled all 17 regex patterns (`Pattern.compile(...)`) as static top-level constants (`PATTERN_VIDEO_TITLE`, `PATTERN_ENCODED_ID`, `PATTERN_URL_LOW`, etc.), completely eliminating runtime `ConcurrentHashMap` lookups, key hashing, and lock contention during video playback configuration extraction.
- Replaced `listOf(videoUrlLow, videoUrlHigh, videoHLS).any { !it.isNullOrBlank() }` (allocating a short-lived `ArrayList` and iterator on every player parsing call) with direct short-circuiting boolean expression `!videoUrlLow.isNullOrBlank() || !videoUrlHigh.isNullOrBlank() || !videoHLS.isNullOrBlank()`.
- Replaced `listOf()` with `emptyList()` for `sponsors` initialization.

### Pass 715 (`:feature-x` — `parserItemVideo.kt` & `parserListVideo.kt`)
- In `parserItemVideo.kt`, added fast-path check `if (html.isBlank() || !html.contains(PLAYER_MARKER)) return null` to avoid parsing full Jsoup HTML DOM trees when the player script marker is absent (e.g. error pages, 404, or blocked responses).
- In `parserListVideo.kt`, optimized `parseSiteCountryFlag` by querying `document.selectFirst("#site-localisation")?.outerHtml()` instead of serializing the entire selected element collection with `document.select("#site-localisation").toString()`.

### Pass 716 (`:feature-x` — `parserVideoPreviewFromImageUrl.kt` & `parserItemVideoTags.kt`)
- In `parserVideoPreviewFromImageUrl.kt`, replaced `parts.dropLast(1).joinToString("/") + "/preview.mp4"` (allocating sublist and string concatenation) with direct string slicing `url.substringBeforeLast('/') + "/preview.mp4"`.
- In `parserItemVideoTags.kt`, replaced chained `.map { }.filter { }.distinct().sorted()` allocations with single-pass `.mapNotNull { it.text().trim().takeIf { s -> s.isNotEmpty() } }.toSortedSet().toList()`.

### Pass 717 (`:feature-x` — `SavedX_Downloads.kt`)
- Replaced 3 separate array filter and transformation passes over `allFiles` (`filter { mp4 }`, `filter { jpg }`, `filter { info }`) with a single $O(N)$ loop categorizing files into `videoIds: HashSet<Long>`, `posterIds: HashSet<Long>`, and `infos: ArrayList<File>`, significantly reducing intermediate collection allocations when scanning downloads on disk.

### Pass 718 (`:feature-x` — `SavedX_History.kt` & `SavedX_Favorites.kt`)
- In `SavedX_History.kt`, collected `deletedIds` into `HashSet<Long>` directly during batch deletion to avoid allocating an intermediate `List` followed by `.toSet()`.
- In `SavedX_History.kt` and `SavedX_Favorites.kt`, replaced full list scan `list.removeAll { it.id == item.id }` with `indexOfFirst` and `removeAt` when updating existing items.
- In `SavedX_Favorites.kt`, removed `mutationJob?.cancel()` that cancelled in-flight disk writes when multiple favorites were toggled quickly.

### Pass 719 (`:feature-l` — `LDownloadRecovery.kt` & `KtorRequestHandler.kt`)
- In `LDownloadRecovery.kt`, replaced `listOf(...).flatMap { ...walkTopDown().filter{}.toList() }` with an indexed `arrayOf` iteration appending directly to a single `ArrayList<File>`, avoiding multiple intermediate lists during recovery scans.
- In `KtorRequestHandler.kt`, marked `username` and `password` as `@Volatile` and snapshotted them into local variables in `login()` to eliminate race conditions between authentication calls and background parameter updates.

### Pass 720 (`:feature-r` — `Downloader.kt` & `AppDns.kt`)
- In `Downloader.kt`, replaced `(item.userName == "") || (item.id == "")` with `item.userName.isBlank() || item.id.isBlank()`.
- In `AppDns.kt`, replaced chained `.map { it.hostAddress ?: "" }.filter { it.isNotEmpty() }` with single-pass `.mapNotNull { it.hostAddress?.takeIf { s -> s.isNotEmpty() } }`.
