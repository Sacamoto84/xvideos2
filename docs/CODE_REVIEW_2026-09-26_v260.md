### Pass 937 (`:core` — `DohModels.kt`)
- **Finding:** `DohResponse`, `DohQuestion`, `DohAnswer`, and `DohDiagnosticResult` lacked status inspection helpers (`isSuccess`, `hasAnswers`, `isEmpty`, `isNotEmpty`, `isValid`, `isA`, `isAaaa`), and lacked standard `EMPTY` sentinel constants.
- **Fix:** Added `isSuccess`, `hasAnswers`, `isEmpty`, `isNotEmpty`, and `DohResponse.EMPTY`; `isValid` and `DohQuestion.EMPTY`; `isValid`, `isA`, `isAaaa`, and `DohAnswer.EMPTY`; `isSuccess` and `count` to `DohDiagnosticResult`.

---

### Pass 938 (`:core` — `DohProvider.kt`)
- **Finding:** `DohProvider` lacked convenient provider type assertions (`isCustom`, `isCloudflare`, `isGoogle`, `isAdGuard`) and standard default provider constant `DEFAULT`.
- **Fix:** Added `isCustom`, `isCloudflare`, `isGoogle`, `isAdGuard` computed properties and defined `DohProvider.DEFAULT = CLOUDFLARE`.

---

### Pass 939 (`:core` — `Status.kt` in `kdownloader`)
- **Finding:** `Status` enum in `kdownloader` required repetitive `when` or equality checks across repository and notification components to check termination, running, or queued states.
- **Fix:** Added `isFinished`, `isRunning`, `isPaused`, `isQueued`, and `isCompleted` extension/computed properties.

---

### Pass 940 (`:feature-l` — `Display.kt`)
- **Finding:** `DataAlbumFilterDisplay` lacked validation checks, sort order classification (`isByTopRated`, `isByFirstLetter`, `isByDate`), an `EMPTY` sentinel, and a centralized lookup function by `request` query string.
- **Fix:** Added `isValid`, `isByTopRated`, `isByFirstLetter`, `isByDate`, `EMPTY` to `DataAlbumFilterDisplay`, and `findAlbumFilterDisplayByRequest(request: String?)`.

---

### Pass 941 (`:feature-l` — `RepositoryResult.kt`)
- **Finding:** Callers handling `RepositoryResult.Error` often had to perform type casts or verbose pattern matching just to retrieve an error message or throwable.
- **Fix:** Added `errorMessageOrNull(): String?` and `throwableOrNull(): Throwable?` helper extensions on `RepositoryResult<T>`.

### Pass 942 (`:feature-r` — `MediaResponse.kt`)
