## Summary of Passes (769–776)

### Pass 769 — `:feature-r` (`Route.kt`)
- **Finding:** In `Route.fillPlaceholders()`, `parameters.toMap()` converted the `vararg Pair<String, Any>` array into a new `LinkedHashMap` and map entry objects on every route construction, even though routes typically contain only 1–5 parameters.
- **Fix:** Switched `fillPlaceholders` to take `Array<out Pair<String, Any>>` directly and perform an in-place lookup (`params.firstOrNull { it.first == key }?.second`), eliminating map allocation and hashing overhead on every API call.

### Pass 770 — `:feature-r` (`R_SearchNiches.kt`)
- **Finding:** In `suggestionsFor()`, `savedRed.nichesCache.list.filter { ... }.map { ... }` traversed the local niche list twice and allocated two intermediate lists, while `remoteResults.map { ... }` allocated another intermediate list, before all were inserted into `combinedMap`.
- **Fix:** Populated `combinedMap` in a single pass directly from `remoteList` and `localList`, eliminating 3 intermediate list allocations on every query change.

### Pass 771 — `:feature-r` (`UsersRed.kt`)
- **Finding:** `UsersRed.listAllUsers` called `usersMap.values.toList()`, which allocates an intermediate collection iterator and list copy on every access even when empty.
- **Fix:** Short-circuited with `emptyList()` when `usersMap.isEmpty()` and constructed `ArrayList(usersMap.values)` directly.

### Pass 772 — `:feature-l` (`AlbumPicsDetails.kt`)
- **Finding:** `normalizePictureUrls(l: List<PicsDetails>)` unconditionally executed `.copy(...)` on every `PicsDetails` in an album (hundreds of items), even when `is_animated` and `url_to_original` were already valid.
- **Fix:** Added identity check (`if (item.is_animated == isAnimated && item.url_to_original == normalizedOriginal) item else item.copy(...)`) and returned the original list reference when no items required modification, eliminating hundreds of object copies per album view.

### Pass 773 — `:feature-l` (`AlbumPicsDetails.kt`)
- **Finding:** In `appendPage()`, rebuilding non-contiguous pages used `(1..pages).flatMap { loadedPages[it].orEmpty() }`, which created intermediate sequences, ranges, and list allocations.
- **Fix:** Replaced `flatMap` with a pre-sized `ArrayList<PicsDetails>(totalLoaded)` loop over `1..pages`.

### Pass 774 — `:feature-x` (`parseHTML5Player.kt`)
- **Finding:** `unescapeUrl()` called `.replace("\\/", "/")` unconditionally on all URLs, performing pattern matching and string copy allocations even when the URL contained no escaped slashes.
- **Fix:** Added `if (contains("\\/")) replace("\\/", "/") else this` to skip regex replacement for already-clean URLs.

### Pass 775 — `:feature-x` (`parserItemVideo.kt`)
- **Finding:** `parserItemVideo(document)` executed `document.select("#video-player-bg script")` and then fell back to a full DOM selector `document.select("script")`, parsing CSS selectors repeatedly.
- **Fix:** Selected `#video-player-bg` once via `selectFirst("#video-player-bg")` and queried `getElementsByTag("script")` directly.

### Pass 776 — `:core` (`AtomicWrite.kt`)
- **Finding:** `File.writeTextAtomically()` invoked the `parentFile` getter multiple times (`parentFile?.mkdirs()`, `createTempFile(..., parentFile)`), creating redundant `File` objects.
- **Fix:** Cached `val parent = parentFile` once and checked for null safety.
