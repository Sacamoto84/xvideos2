# Code Review & Optimization Report — Batch 46 (v262)

**Date:** 2026-09-26  
**Passes:** 953 – 960  
**Scope:** Numerical and textual formatting utilities, folder calculation nullability safety, preset filter query lookups, section R saved counter and paging source validation, section X URL classification and ID extraction robustness, and local webserver IP/port validation helpers.

---

### Pass 953 (`:core` — `toPrettyCount.kt`)
- **Finding:** `toPrettyCount` variants only accepted `Long`, forcing callers with integer counters to cast to `Long`, and UI callers parsing string view counts had to write verbose `.toLongOrNull()?.toPrettyCount() ?: default` expressions.
- **Fix:** Added `Int` overloads for `toPrettyCount()`, `toPrettyCount2()`, `toPrettyCount3()`, `toPrettyCountInt()`, and introduced `String?.toPrettyCountOrDefault(default: String = "0"): String`.

---

### Pass 954 (`:core` — `capitalizeEachWord.kt`)
- **Finding:** Callers formatting nullable author, tag, or title strings had to perform repetitive null-checks (`str?.capitalizeEachWord() ?: ""`).
- **Fix:** Added `String?.capitalizeEachWordOrEmpty(): String` extension.

---

### Pass 955 (`:core` — `getFolderSize.kt`)
- **Finding:** `getFolderSize(dir: File)` required a non-null `File` reference, causing potential NPEs or requiring caller-side null checks.
- **Fix:** Unified `getFolderSize(dir: File?): Long` to safely handle `null`, non-existent, or non-directory files returning `0L`, and added `File?.folderSize(): Long` receiver extension.

---

### Pass 956 (`:core` — `toTwoDecimalPlacesWithColon.kt`)
- **Finding:** Decimal colon formatting only supported `Float`, forcing callers with `Double` or nullable string values to write boilerplate conversion code.
- **Fix:** Added `Double.toTwoDecimalPlacesWithColon()` and `String?.toTwoDecimalPlacesWithColonOrDefault(default: String = "0:00")`.

---

### Pass 957 (`:feature-l` — `AlbumFilterPresetManager.kt`)
- **Finding:** `AlbumFilterPresetManager` only exposed raw list operations without query helpers to lookup presets by ID or name, or check preset existence.
- **Fix:** Added `getPresetById(id)`, `getPresetByName(name)`, `hasPreset(name)`, and inspection properties `count`, `isEmpty`, and `isNotEmpty`.

---

### Pass 958 (`:feature-r` — `SavedRed.kt` & `ItemCollectionPagingSource.kt`)
- **Finding:** `ItemCollectionPagingSource` used `isNullOrEmpty()` rather than filtering whitespace strings, and lacked a property to inspect whether a valid collection was targeted. `SavedRed` lacked an aggregate count of all saved items across categories.
- **Fix:** In `ItemCollectionPagingSource`, switched to `isNullOrBlank()` and added `hasCollection: Boolean`. In `SavedRed`, added `totalSavedCount: Int`.

---

### Pass 959 (`:feature-x` — `XSite.kt`)
- **Finding:** URL validation and video ID extraction lacked standalone URL classifier functions and didn't guard against blank/whitespace URLs before evaluating regexes.
- **Fix:** Hardened `extractXVideoId` with `isBlank()` check, added `isXVideoUrl(href: String): Boolean`, `isValidXUrl(href: String): Boolean`, and `String.toNormalizedXUrl(): String`.

---

### Pass 960 (`:core` — `NetworkIpHelper.kt`)
- **Finding:** `NetworkIpHelper.buildServerUrl` did not validate port ranges (allowing negative numbers or numbers exceeding 65535) or blank IP inputs, and lacked standalone port and IPv4 validators.
- **Fix:** Added `isValidPort(port: Int): Boolean`, `isValidIpv4(ip: String?): Boolean`, and updated `buildServerUrl` to return empty string for blank IPs or invalid ports.
