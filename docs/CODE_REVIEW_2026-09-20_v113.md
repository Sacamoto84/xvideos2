# Код-ревью: Итерация 134 (2026-09-20)

**Фокус ревью:** Иерархическая навигация и закрытие диалогов по системной кнопке «Назад» во всех сохранённых вкладках и разделах настроек (`AppLockSection`, `NetworkSettingsSection`, `R_Screen_CollectionTab`, `R_Screen_Saved_SubscriptionsTab`, `SavedNichesTab`, `R_Screen_CreatorsTab`, `L_Screen_CollectionTab`, `L_DialogCollection`, `ScreenAlbum`), стандартизация форматирования размеров хранилища в `RSettingsSection` с переходом на `formatBytes()`.

---

## 1. Контекст и цели

1. **[NAV03] Иерархическое закрытие диалогов подтверждения и действий по нажатию «Назад» (`:app`, `:feature-r`, `:feature-l`)**:
   - Во множестве Compose-экранов с модальными диалогами подтверждения удаления или контекстными меню отсутствовали обработчики `BackHandler(enabled = isDialogOpen)`.
   - В результате системный жест или кнопка «Назад» при открытом диалоге перехватывались родительскими экранами или навигаторами (Voyager Navigator), что приводило к неожиданному переключению вкладок, выходу из экрана или закрытию приложения вместо интуитивного закрытия поверхностного диалога.
   - *Решение:*
     - В `AppLockSection.kt` добавлен `BackHandler(enabled = dialogMode != null || showCamouflageVerificationDialog || showTimeoutDialog)`, безопасно закрывающий диалоги ввода PIN/пароля, верификации камуфляжа и таймаута блокировки.
     - В `NetworkSettingsSection.kt` добавлен `BackHandler(enabled = showCustomUrlDialog)` для закрытия диалога ввода кастомного адреса DoH сервера.
     - В `R_Screen_CollectionTab.kt` добавлен `BackHandler(enabled = selectedCollection == null && (itemPendingAction != null || itemPendingRename != null || itemPendingDelete != null))` для закрытия меню действий, переименования и удаления коллекции.
     - В `R_Screen_Saved_SubscriptionsTab.kt` добавлен `BackHandler(enabled = userToDelete != null)` для закрытия диалога отписки.
     - В `SavedNichesTab.kt` добавлен `BackHandler(enabled = itemPendingDelete != null)` для закрытия диалога удаления ниши.
     - В `R_Screen_CreatorsTab.kt` добавлен `BackHandler(enabled = itemPendingDelete != null)` для закрытия диалога удаления автора.
     - В `L_Screen_CollectionTab.kt` добавлен `BackHandler(enabled = selectedCollection == null && (itemPendingAction != null || itemPendingRename != null || itemPendingDelete != null))` для закрытия меню действий, переименования и удаления коллекции L.
     - В `L_DialogCollection.kt` (`LCollectionDialogs`) добавлен `BackHandler(enabled = isAnyDialogOpen)` для закрытия диалогов создания новой коллекции и выбора коллекции.
     - В `ScreenAlbum.kt` добавлен приоритетный перехват `itemPendingDelete != null` в `BackHandler` и экранной кнопке возврата `IconButton(onClick = ...)` перед закрытием экрана или сбросом фильтра анимаций.

2. **[UI05] Стандартизация форматирования размеров папок Red в `RSettingsSection` (`:app`)**:
   - В `RSettingsSection.kt` значения `sizeRedTotal` и `sizeRedDownload` (получаемые из `getFolderSize()`, возвращающего размер в байтах) форматировались с помощью `toPrettyCount3()`. Функция `toPrettyCount3()` форматирует сырые счётчики элементов (с суффиксами `K`, `M`, `B`), приводя к некорректным отображениям вида `250.000M` вместо `250.0 MB`.
   - *Решение:*
     - Заменено форматирование на `formatBytes(sizeRedTotal)` и `formatBytes(sizeRedDownload)`, обеспечивая единый стандарт отображения дискового пространства приложения.

## 2. Выявленные замечания и исправления

### [NAV03] Иерархическое закрытие модальных окон и диалогов по кнопке «Назад»
- **Проблема:** Диалоги подтверждения удаления (`DeleteCreatorDialog`, `DialogNicheDelete`, `DialogSubscriptionDelete`, `AlbumDialogDeleteAlbum`, `DaialogNewCollection`, `AppLockPasswordDialog`, `CustomDohUrlDialog`) закрывались только по тапу вне диалога или по явной кнопке отмены. Системное нажатие «Назад» пробивалось сквозь диалог в навигатор экрана.
- **Решение:** Внедрены управляемые `BackHandler` во всех затронутых компонентах.
- **Статус:** Исправлено.

### [UI05] Единый формат байтовых размеров хранилища в RSettingsSection
- **Проблема:** Использование `toPrettyCount3()` для размеров файлов и папок в `RSettingsSection.kt` давало вводящие в заблуждение суффиксы без указания единиц измерения (`B`, `KB`, `MB`, `GB`).
- **Решение:** Форматирование переведено на общую утилиту `formatBytes()`.
- **Статус:** Исправлено.
