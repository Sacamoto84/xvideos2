[feature-l/.../saved/SavedL_Likes.kt:74](../feature-l/src/main/java/com/client/xvideos/l/featured/saved/SavedL_Likes.kt:74)

### C3 — Идентификатор пользователя сессии переживает выход и смену аккаунта. Средняя.

[feature-l/.../repository/…ServerFavoritesRepositoryImpl.kt:48](../feature-l/src/main/java/com/client/xvideos/l/repository/LusciousServerFavoritesRepositoryImpl.kt:48)

`getSessionUserId()` берёт `user_id` из глобального `mediaCategoriesFlow`. Он
не сбрасывается при смене профиля и восстанавливается из ROM-кэша справочника
([MediaCategoriesBootstrap.kt:31](../feature-l/src/main/java/com/client/xvideos/l/net/graphQl/MediaCategoriesBootstrap.kt:31)):
срок кэша — 7 дней, ключ от сессии не зависит.

Пользователь A вышел или вошёл как B — в памяти и в кэше остаётся `user_id` A,
в том числе после перезапуска. Вкладки «лайки на сервере» и «подписки»
запрашивают списки по id A: B видит избранное A, а снятие лайка уходит в сессию
B. Вместе с `user_id` устаревают и настройки фильтров из того же ответа.

Чего у находки нет: что сервер отдаёт по чужому id анониму, не проверялось.

### Как закрыты

- **C1, C4, A2.** Разбор ответов в репозитории серверного избранного идёт
  через `objectAt` / `contentOrNull` / `errorMessagesOrNull`: `null` на любом
  уровне не бросает исключение, `errors: null` не считается ошибкой, альбом
  без id — `null`, а не строка `"null"`. `resolvePictureId` исключений наружу
  не выпускает.
- **C6.** Поиск id картинки идёт до ста страниц альбома; если не нашлось,
  сообщение говорит, сколько страниц просмотрено из скольких.
- **C3.** Идентификатор пользователя сессии берётся из свежего ответа сервера
  и помнится вместе с номером записи профиля: после выхода или смены аккаунта
  прежний id не используется. `LServerFavoritesRepositoryImplTest` — 11 тестов.
- **C7.** Тексты ошибок — по-русски и без названия сайта; первичная загрузка,
  обновление и снятие подписки показывают `toLUserMessage()`.
- **C2, T3, A3.** Пагинация обеих вкладок вынесена в `LServerPagedList`:
  обновление хранит свой `Job`, подгрузка во время обновления не стартует,
  флаги снимаются в `finally`. После сбоя подгрузки автоподгрузка выключена,
  пока пользователь не отойдёт от конца списка. `LServerPagedListTest` — 7
  тестов.
- **T1, T2, A1, C8.** Мутации лайков и альбомов выполняет очередь
  `LMutationQueue`: по одной, без отмены предыдущей. Новый лайк дописывается в
  список без перечитывания каталога; удаление альбома убирает и кэш его
  картинок. `LLikesConcurrencyTest` — 4 теста, `SavedL_AlbumsQueueTest` — 3.
- **C9.** Локальный файл копируется во временный и переименовывается
  (`lCopyFileAtomically`). `LCopyFileAtomicallyTest` — 3 теста.
- **C5.** `saveAlbum()` своего снекбара не показывает: результат сообщает
  хранилище. Теста нет.

Тесты, кроме C5, написаны до правок.
