## Summary of Passes (849–856)

### Pass 849 — `:core` (`formatBytes.kt`)
- **Finding:** In `formatBytes(bytes)`, values `<= 0L` or `< ONE_KB` entered a `when` block evaluating floating point divisions before deciding whether to format as bytes or kilobytes.
- **Fix:** Added immediate top-level fast exits `if (bytes <= 0L) return "0 B"` and `if (bytes < ONE_KB) return "$bytes B"` bypassing all floating-point math for non-positive or small byte values.

### Pass 850 — `:core` (`formatSpeed.kt`)
- **Finding:** In `formatSpeed(bytesPerSecond)`, non-positive values or small rates `< ONE_KB` executed full pattern branches with floating point calculations.
- **Fix:** Added direct guards `if (bytesPerSecond <= 0L) return "0 Bs"` and `if (bytesPerSecond < ONE_KB) return "$bytesPerSecond Bs"`.

### Pass 851 — `:core` (`toMinSec.kt`)
- **Finding:** Every call to `Double.toMinSec()` and `Float.toMinSec()` allocated two separate intermediate strings (`mStr` and `sStr`) for values under 10 (e.g. `"0$minutes"` and `"0$seconds"`), creating thousands of ephemeral string allocations during playback timelines and list rendering.
- **Fix:** Introduced a static pre-computed array `DIGIT_STRINGS = Array(60) { ... }`, providing zero-allocation two-digit string lookups for minutes `< 60` and seconds `< 60`.

### Pass 852 — `:feature-x` (`parserVideoPreviewFromImageUrl.kt`)
- **Finding:** In `parserVideoPreviewFromImageUrl(s)`, `source.isBlank()` re-scanned whitespace on already-trimmed strings. In hash parsing, `replace(TRAILING_INDEX_REGEX, "")` ran regex pattern matching unconditionally across all file names even when no hyphens were present.
- **Fix:** Switched `source.isBlank()` to $O(1)$ `source.isEmpty()`, and guarded regex execution with `if (rawHash.contains('-'))`, avoiding regex evaluation for standard 32-character hex hashes.

### Pass 853 — `:feature-x` (`parseHTML5Player.kt`)
- **Finding:** `parseHTML5Player(script)` unconditionally executed 17 regex pattern matchers across potentially large script texts even when the script did not contain player code.
- **Fix:** Added early keyword guard `if (trimmed.isEmpty() || !trimmed.contains("html5player")) return null` before running any regex pattern matchers.

### Pass 854 — `:core` (`AppLockThrottle.kt`)
- **Finding:** `remainingMillis(state, wallNow, elapsedNow)` performed timestamp arithmetic and coercions on every lock check even when no lockouts were active. `onFailedAttempt` did not guard against negative attempt inputs.
- **Fix:** Added fast return `if (state.lockoutUntilWall <= 0L && state.lockoutUntilElapsed <= 0L) return 0L`, guarded negative attempts, and provided `State.isLocked` helper and `State.INITIAL` singleton.

### Pass 855 — `:feature-l` (`FilterGenre.kt`)
- **Finding:** Callers frequently needed to verify that a genre had valid non-blank identification and extract a display name, duplicating fallback logic.
- **Fix:** Added domain extensions `FilterGenre.isValid: Boolean` and `FilterGenre.displayTitle: String` providing clean zero-allocation property access.

### Pass 856 — `:feature-r` (`TagInfo.kt` & `TagSuggestion.kt`)
- **Finding:** Consumers of `TagInfo` and `TagSuggestion` frequently instantiated empty model instances and performed repetitive blank string checks on tag names.
- **Fix:** Added `isValid: Boolean` properties and `EMPTY` companion object singletons to both `TagInfo` and `TagSuggestion`.
