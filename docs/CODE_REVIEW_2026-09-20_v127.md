База прохода `edc3fdd`, введение канонических расширений `isScrolled` для `LazyListState` и `LazyGridState` (`:core`) с учётом внутриэлементного смещения (`firstVisibleItemScrollOffset > 0`) и их внедрение в экраны поиска и библиотеки (`:feature-r`, `:feature-x`).

## Находки

### C1 — Потеря состояния прокрутки при частичном скролле внутри первого элемента списка/сетки. Средняя.

[feature-x/src/main/java/com/client/xvideos/x/screens/saved/ScreenSavedX.kt:79](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/saved/ScreenSavedX.kt#L79)
[feature-x/src/main/java/com/client/xvideos/x/screens/favorites/ScreenFavorites.kt:124](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/favorites/ScreenFavorites.kt#L124)

При проверке необходимости скролла к началу использовалось условие `state.firstVisibleItemIndex > 0`.
Если пользователь прокручивал список вниз, но первый элемент оставался частично виден (например, крупная шапка карточки автора, высокий элемент видео или просто смещение на несколько сотен пикселей), значение `firstVisibleItemIndex` оставалось равным `0`, а смещение `firstVisibleItemScrollOffset` становилось положительным.
В результате `BackHandler` считал, что экран находится в самом верху (`enabled = false`), и вместо плавной прокрутки к началу нажатие кнопки «Назад» немедленно переключало вкладку или закрывало экран.

**Решение:**
1. В модуль `:core` (`com.client.xvideos.common.ui.lazy`) добавлены канонические расширения `LazyScrollExtensions.kt`:
   ```kotlin
   val LazyListState.isScrolled: Boolean
       get() = firstVisibleItemIndex > 0 || firstVisibleItemScrollOffset > 0

   val LazyGridState.isScrolled: Boolean
       get() = firstVisibleItemIndex > 0 || firstVisibleItemScrollOffset > 0
   ```
2. В `SearchTab.kt`, `ScreenSavedX.kt` и `ScreenFavorites.kt` обработчики `BackHandler` переведены на использование `.isScrolled`.
3. Создан модульный тест `LazyScrollExtensionsTest.kt` в `:core`, покрывающий нулевые состояния, внутриэлементные смещения и межэлементную прокрутку для списков и сеток.
