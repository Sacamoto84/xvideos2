# Code Review & Optimization Report — Batch 37 (v253)

**Date:** 2026-09-25  
**Passes:** 881 – 888  
**Scope:** Coil image loading progress tracking, snackbar visuals and messaging, display column selection, thumbnail size preferences, ExoPlayer HLS helper routines, playback speed models, and flag emoji conversions.

---

### Pass 881 (`:core` — `ProgressResponseBody.kt`)
- **Finding:** In `ProgressResponseBody.source()`, `responseBody.contentLength()` was queried on every buffer read chunk during streaming, incurring repetitive method dispatch for an unchanging HTTP header value.
- **Fix:** Cached `val totalLength = responseBody.contentLength()` once in the `source()` factory before returning `ForwardingSource`.

---

### Pass 882 (`:core` — `ProgressInterceptor.kt`)
- **Finding:** Non-successful responses (such as 404 Not Found or 500 Server Error) had their response bodies wrapped in `ProgressResponseBody`, triggering progress callbacks for error responses.
- **Fix:** Added `!originalResponse.isSuccessful` early check to bypass progress wrapping for non-2xx responses.

---

### Pass 883 (`:core` — `UiMessage.kt`)
- **Finding:** `UiMessage` lacked type check helpers (`isError`, `isSuccess`, etc.) forcing manual `is` branching at call sites. `SnackbarHostState.show(ui)` did not guard against blank message strings.
- **Fix:** Added `isError`, `isSuccess`, `isWarning`, `isInfo`, and `isNotEmpty` extension properties, and added `if (ui.text.isBlank()) return` in `show(ui)`.

---

### Pass 884 (`:core` — `ColumnSelect.kt`)
- **Finding:** `ColumnSelect_AddColumn` did not guard against empty flag lists and would re-set preferences even when only a single column option was enabled and already selected.
- **Fix:** Added `if (flags.isEmpty()) return` and short-circuited when `enabledIndices.size == 1 && enabledIndices[0] == currentIndex`.

---

### Pass 885 (`:core` — `ThumbnailsSize.kt`)
- **Finding:** `fromValue` and `fromDisplayName` did not check for empty input and performed exact case comparisons, failing on mixed-case settings.
- **Fix:** Added empty string fast paths, switched to case-insensitive comparison (`equals(..., ignoreCase = true)`), and introduced companion `DEFAULT = SMALL`.

---

### Pass 886 (`:core` — `ExoplayerHelper.kt`)
- **Finding:** `isHlsUrl(url)` unconditionally split URLs by `?` and `#` even for standard `.m3u8` links without query parameters or fragments.
- **Fix:** Fast-pathed `trimmed.endsWith(".m3u8", ignoreCase = true)` before performing substring operations.

---

### Pass 887 (`:core` — `enumPlayerSpeed.kt`)
- **Finding:** `PlayerSpeed` lacked a fast lookup from float speed and normal-speed helper. `ScreenResize` lacked convenience getters.
- **Fix:** Added `isNormal: Boolean` and `fromSpeed(speed: Float)` to `PlayerSpeed`. Added `isFit` and `isFill` helper properties to `ScreenResize`.

---

### Pass 888 (`:feature-x` — `CountryFlag.kt`)
- **Finding:** `getFlagEmoji` allocated a new `raw.uppercase()` String object on every flag emoji conversion.
- **Fix:** Replaced intermediate string allocation with direct character-level checks using `uppercaseChar()` on index 0 and 1.
