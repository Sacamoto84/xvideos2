## 1. Контекст и цели прохода

В рамках прохода 171 проведён детальный аудит избыточных аллокаций памяти и стабилизации лямбда-коллбеков при рекомпозиции экранов в модулях Luscious (`:feature-l`), Red (`:feature-r`) и X (`:feature-x`):

1. **Мемоизация маппинга коллекций в сетку (`L_Screen_CollectionTab.kt` и `R_Screen_CollectionTab.kt`)**:
   - **Проблема**: В компонентах `L_SavedCollectionTabContent` и `R_SavedCollectionTabContent` аргумент `collections` вычислялся непосредственно в вызове через `collectionList.map { CollectionGridItem(...) }`. При любой рекомпозиции (включая скролл или открытие диалогов) заново создавался список и аллоцировались новые объекты элементов сетки.
   - **Решение**: Выделен мемоизированный список `val gridItems = remember(collectionList) { collectionList.map { ... } }`, гарантирующий стабильность ссылок.

2. **Вынос статических опций фильтра лайков (`L_ScreenSavedLikesTab.kt` в `:feature-l`)**:
   - **Проблема**: Список `val options = listOf("All", "Image", "Gif")` создавался заново на каждой рекомпозиции вкладки «Сохранённые лайки».
   - **Решение**: Вынесен в неизменяемую константу уровня файла `private val LIKES_FILTER_OPTIONS = listOf("All", "Image", "Gif")`.

3. **Мемоизация расчёта аудиторий в фильтре альбомов (`AlbumListFilterAudiences.kt` в `:feature-l`)**:
   - **Проблема**: На каждой рекомпозиции пересчитывались `allIds = audiences.map { it.id }.toSet()`, `selectedIds`, `isAllSelected` и формировалась строка `summaryText` через `joinToString`.
   - **Решение**: Все вычисления обёрнуты в `remember` с зависимостями `audiences`, `filter.audienceIds`, `allIds`, `selectedIds`, исключая избыточные преобразования коллекций.

4. **Стабилизация коллбеков экрана «Избранное» (`ScreenFavorites.kt` в `:feature-x`)**:
   - **Проблема**: Функции `localUrlOf`, `posterUrlOf`, `onDelete`, `onDownload`, `onSaveToGallery`, `onPlayLocal`, `onOpenVideo` передавались в `FavoritesContent` как анонимные лямбды, создаваемые заново на каждом кадре, что приводило к срыву пропускаемости рекомпозиций `FavoritesContent`.
   - **Решение**: Все лямбды стабилизированы с помощью `remember` с соответствующими ключами зависимостей (`downloadedIds`, `vm.saved`, `vm`, `navigator`).

5. **Инварианты**:
   - P2P модуль (`core/.../p2p/`) строго заморожен и не изменялся.
