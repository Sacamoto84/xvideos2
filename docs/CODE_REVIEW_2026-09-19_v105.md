## 1. Контекст и цели

1. **[C46] Исправление безусловного отображения бейджа верификации в `RedProfileUserImage.kt` (`:feature-r`)**:
   - Иконка верификации автора `R.drawable.verificed` рисовалась безусловно для всех пользователей, игнорируя булево поле модели `item.verified`. В результате любой автор (даже без верификации) отображался с золотой галочкой проверенного автора.
   - Также в разметке корневой `Column` содержал лишний `Modifier.systemBarsPadding()`, создававший двойной верхний отступ под верхней панелью экрана.
   - *Решение:*
     - Обернуть `Image(painter = painterResource(id = R.drawable.verificed))` в проверку `if (item.verified)` и задать `contentDescription = "Verified Creator"`.
     - Заменить устаревший импорт `com.composeunstyled.Text` на стандартный `androidx.compose.material3.Text`, удалить избыточные вызовы `.toString()` на строковых полях и убрать дублирующий `systemBarsPadding()`.
2. **[UI46] Внутриэкранная навигация «Назад», заголовок и `BackHandler` в `ScreenRedProfile.kt` (`:feature-r`)**:
   - При переходе в профиль автора (из поиска `SearchTab`, табов сохранённого или экрана видео) экран профиля не имел верхней панели и кнопки «Назад». На устройствах с кнопочной панелью навигации или при медленной загрузке данных пользователь не мог комфортно вернуться назад.
   - Отсутствовал явный Compose `BackHandler`.
   - *Решение:*
     - Добавить `BackHandler { navigator.pop() }`.
     - Обернуть экран в `Scaffold` с верхней панелью, содержащей `IconButton(Icons.AutoMirrored.Filled.ArrowBack)` и имя/никнейм автора (`creator?.name?.ifBlank { creator.username } ?: profileName`).
3. **[UI47] Верхняя панель навигации, заголовок и декомпозиция `ScreenLAlbumLandingTag.kt` (`:feature-l`)**:
   - Экран тега Luscious открывался по клику на тег альбома, но не имел верхней панели с кнопкой «Назад» и `BackHandler`. Если сетевой запрос задерживался, верхняя часть экрана оставалась пустой.
   - Заголовок тега выводился элементом `LazyColumn`, смещаясь при скролле.
   - *Решение:*
     - Добавить `BackHandler { navigator.pop() }`.
     - Добавить `Scaffold(topBar = { LandingTagTopBar(...) })` с кнопкой возврата и фиксированным заголовком тега `Tag: ${title ?: tag}`.
     - Декомпозировать разметку на легковесные компоненты `LandingTagTopBar` и `LandingTagSectionItem`, снизив длину `Content()` со 123 до ~40 строк и строго соблюдая лимит Detekt `LongMethod` (макс. 120 строк).
4. **[UI48] Поддержка заголовка и кнопки «Назад» в `ScreenAlbumList.kt` (`:feature-l`)**:
   - Функция `L_ScreenAlbumList.create(filter, title)` принимает параметр `title`, который передавался из 5 различных мест (поиск, жанры, аудитории, теги, топ-хиты), однако в сетке `AlbumListPageGrid` отсутствовала кнопка возврата по стеку навигации.
   - В `ScreenAlbumListContent` отсутствовал `BackHandler`.
   - *Решение:*
     - Добавить `BackHandler(enabled = navigator.canPop) { navigator.pop() }`.
     - В `AlbumListPageGrid` при наличии `title` и `navigator.canPop` добавить кнопку возврата `IconButton(Icons.AutoMirrored.Filled.ArrowBack)`.
5. **[T56] Тестирование сериализации и модели `UserInfo` (`:feature-r`, `:feature-l`)**:
   - Добавлен `UserInfoSerializationTest`: проверка разбора JSON с `verified = true/false`, пропущенного флага (дефолт `false`), больших метрик и выживаемости `ScreenRedProfile` в Java serialization стека Voyager.
   - Добавлен `ScreenLAlbumLandingTagSerializationTest`: проверка выживаемости экрана тегов альбомов в сохранённом состоянии Android.

## 2. Выявленные замечания и исправления

### [C46] Исправление бейджа верификации и гигиена Text
- **Проблема:** В [RedProfileUserImage.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/profile/atom/RedProfileUserImage.kt) бейдж проверенного автора рисовался всем пользователям без проверки `item.verified`. Использовался deprecated `com.composeunstyled.Text`, вызывались лишние `.toString()`.
- **Решение:** Добавлена проверка `if (item.verified)`, бейджу назначен `contentDescription`, `Text` заменён на Material 3, избыточный `systemBarsPadding()` удалён.
- **Статус:** Исправлено.

### [UI46] Внутриэкранная навигация и BackHandler в ScreenRedProfile
- **Проблема:** В [ScreenRedProfile.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/profile/ScreenRedProfile.kt) отсутствовала кнопка возврата и заголовок при входе в профиль, отсутствовал `BackHandler`.
- **Решение:** Добавлен `BackHandler`, добавлен `Scaffold` с верхней панелью, кнопкой «Назад» и заголовком с fallback на переданный `profileName`.
- **Статус:** Исправлено.

### [UI47] Верхняя панель навигации и декомпозиция экрана тегов Luscious
- **Проблема:** В [ScreenLAlbumLandingTag.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/albumLandingTag/ScreenLAlbumLandingTag.kt) не было кнопки возврата и `BackHandler`. Заголовок находился внутри списка и прокручивался. Метод `Content()` превышал лимит Detekt `LongMethod`.
- **Решение:** Экран дополнен `Scaffold` с `LandingTagTopBar`, выделен компонент `LandingTagSectionItem`, добавлен `BackHandler`.
- **Статус:** Исправлено.

### [UI48] Кнопка «Назад» и заголовок в списке альбомов Luscious
- **Проблема:** В [ScreenAlbumList.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbumList/ScreenAlbumList.kt) при открытии отфильтрованного списка с заголовком не было кнопки возврата назад, а стек навигации не перехватывал `BackHandler`.
- **Решение:** Добавлен `BackHandler(enabled = navigator.canPop)`, в шапку страницы сетки встроена кнопка «Назад» рядом с переданным заголовком.
- **Статус:** Исправлено.

### [T56] Модульное тестирование сериализации Voyager и моделей
- **Проблема:** Отсутствовало тестирование сериализации `ScreenRedProfile`, `ScreenLAlbumLandingTag` и разбора флага верификации в `UserInfo`.
- **Решение:** Разработаны `UserInfoSerializationTest` и `ScreenLAlbumLandingTagSerializationTest`.
- **Статус:** Исправлено.
