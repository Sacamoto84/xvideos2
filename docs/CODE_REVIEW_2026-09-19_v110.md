# Код-ревью: Итерация 131 (2026-09-19)

**Фокус ревью:** Завершение системного аудита Voyager `ScreenKey`, устранение пробелов в иерархии возвратов `BackHandler` в видеоплеерах RedGifs и X (`ScreenRedFullScreen`, `ScreenX_VideoPlayer`), иерархический переход по подвкладкам `ScreenXDashBoards`, детерминированный ключ стартового экрана `MenuScreen`, устранение предупреждений компилятора Kotlin на платформе Windows и модульное тестирование.

---

## 1. Контекст и цели

1. **[UI63] Завершение контракта детерминированных ScreenKey: стартовое меню `MenuScreen` (`:app`)**:
   - `MenuScreen` оставался последним экраном приложения, использовавшим генерацию случайного `uniqueScreenKey` по умолчанию из Voyager `Screen`.
   - В `AppSettingsScreenSerializationTest` отсутствовала проверка сохранности стабильного ключа после десериализации `MenuScreen`.
   - *Решение:*
     - Задать детерминированный ключ `override val key: ScreenKey = "MenuScreen"`.
     - Дополнить `AppSettingsScreenSerializationTest` проверкой равенства `assertEquals("MenuScreen", restored.key)`.

2. **[UI64] Унификация системной навигации «Назад» в `ScreenRedFullScreen` (`:feature-r`)**:
   - В `RedFullScreenFeed` и `RedFullScreenSingle` обработчики `BackHandler(enabled = isCurrentPageZoomed)` и `BackHandler(enabled = isZoomed)` обрабатывали только сброс зума. При обычном масштабе (1.0x) жест «Назад» не перехватывался экраном плеера, что приводило к паразитному срабатыванию `BackHandler` нижележащего `ScreenExplorer` (переключение вкладки под видео) вместо закрытия плеера.
   - Наэкранная кнопка «Назад» в оверлее вызывала `navigator.pop()`, создавая расхождение в UX между жестом и экранной кнопкой.
   - *Решение:*
     - В `RedFullScreenFeed` и `RedFullScreenSingle` унифицировать `BackHandler`: если кадр увеличен — инкрементировать `resetZoomTrigger`, иначе вызывать `navigator.pop()`.
     - Дополнить `ScreenRedFullScreenSerializationTest` тестом стабильного ключа `RedFullScreen:$id:$startIndex` и round-trip десериализации.

3. **[UI65] Полнота обработки жеста «Назад» в `ScreenX_VideoPlayer` (`:feature-x`)**:
   - В портретном режиме воспроизведения видео в `VideoPlayerContentView` обработчик `BackHandler(enabled = isZoomed)` был активен только при активном зуме. При масштабе 1.0x жест «Назад» не закрывал плеер, в то время как экранная стрелка назад вызывала `navigator.pop()`.
   - *Решение:*
     - В `VideoPlayerContentView` обновить обработчик до `BackHandler(enabled = !vm.isFullScreen)`: при наличии зума сбрасывать масштаб, иначе вызывать `navigator.pop()`.

4. **[UI66] Иерархический возврат по подвкладкам в `ScreenXDashBoards` (`:feature-x`)**:
   - В разделе `Savable` экрана `ScreenXDashBoards` при нахождении во вторичных вкладках (`SAVED_DOWNLOADS`, `SAVED_HISTORY`) жест «Назад» сразу переключал `vm.mainTab = 0`, минуя базовую вкладку `SAVED_FAVORITES`.
   - *Решение:*
     - Реализовать двухступенчатый возврат: если `vm.savedTab != 0`, сбрасывать `vm.savedTab = 0`, иначе возвращаться в основной фид дашбордов `vm.mainTab = 0`.

5. **[C19] Устранение предупреждений компилятора Kotlin на платформе Windows и в тестах**:
   - В `RouteTest.kt` (`:feature-r`) имя тестового метода содержало символ `%`, что вызывало предупреждение компилятора Kotlin о недопустимых символах файловой системы Windows.
   - В `ScreenX_VideoPlayerSMTest.kt` (`:feature-x`) обращение к обратно-совместимому методу `openFullScreen()` вызывало предупреждение о deprecation без подавления аннотацией.
   - *Решение:*
     - Переименовать тестовый метод в `RouteTest.kt` на `пробел кодируется через hex 20, а не плюсом`.
     - Добавить `@Suppress("DEPRECATION")` к тесту `openFullScreen переключает в полный экран на месте`.

## 2. Выявленные замечания и исправления

### [UI63] Детерминированный ключ и тест MenuScreen
- **Проблема:** В [MenuScreen.kt](file:///g:/xvideos2/app/src/main/java/com/client/xvideos/screenRoot/MenuScreen.kt) отсутствовал `override val key: ScreenKey`, порождая недетерминированные UUID Voyager.
- **Решение:** Объявлен ключ `"MenuScreen"`, в `AppSettingsScreenSerializationTest` добавлена валидация ключа.
- **Статус:** Исправлено.

### [UI64] Бесшовный жест «Назад» в ScreenRedFullScreen
- **Проблема:** В [ScreenRedFullScreen.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/fullscreen/ScreenRedFullScreen.kt) жест «Назад» при отсутствии зума не закрывал полноэкранный плеер и активировал смену вкладок в проводнике.
- **Решение:** Унифицирован `BackHandler` в ленточном и одиночном режимах: сброс зума при увеличении, `navigator.pop()` при стандартном масштабе. Добавлен unit-тест `ScreenRedFullScreenSerializationTest`.
- **Статус:** Исправлено.

### [UI65] Полнота обработки BackHandler в ScreenX_VideoPlayer
- **Проблема:** В [ScreenX_VideoPlayer.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/videoplayer/ScreenX_VideoPlayer.kt) в `VideoPlayerContentView` отсутствовал выход из плеера по жесту «Назад» в портретном режиме без зума.
- **Решение:** Настроен `BackHandler(enabled = !vm.isFullScreen)` для сброса зума либо вызова `navigator.pop()`.
- **Статус:** Исправлено.

### [UI66] Иерархический возврат в ScreenXDashBoards
- **Проблема:** В [ScreenXDashBoards.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/ScreenXDashBoards.kt) жест «Назад» из «Истории» и «Загрузок» перескакивал сразу в общие дашборды, минуя «Избранное».
- **Решение:** Подключена ступенчатая логика перехода: `savedTab = 0`, затем `mainTab = 0`.
- **Статус:** Исправлено.

### [C19] Чистка предупреждений компилятора Kotlin
- **Проблема:** Символ `%` в имени теста `RouteTest.kt` на Windows и неподавленный вызов `openFullScreen()` в `ScreenX_VideoPlayerSMTest.kt`.
- **Решение:** Исправлено имя теста, добавлена аннотация `@Suppress("DEPRECATION")`.
- **Статус:** Исправлено.

### [C20] Детерминированная кодировка UUID в extractXVideoId
- **Проблема:** В [XSite.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/XSite.kt) вызов `slugMatch.toByteArray()` использовал дефолтную кодировку платформы.
- **Решение:** Явно указан `Charsets.UTF_8` в `slugMatch.toByteArray(Charsets.UTF_8)` для гарантии независимости от платформы.
- **Статус:** Исправлено.

### [C21] Потокобезопасная очистка истории в SavedX_History
- **Проблема:** В [SavedX_History.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/feature/saved/SavedX_History.kt) в методе `clearAll()` отсутствовал явный сброс реактивного списка `list.clear()` в блоке `withContext(Dispatchers.Main)`.
- **Решение:** Добавлен `list.clear()` на главном потоке рядом с `historyMap.clear()`.
- **Статус:** Исправлено.
