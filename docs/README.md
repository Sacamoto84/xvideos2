## Как вести учёт дальше

1. Новый отчёт создаётся из [шаблона](CODE_REVIEW_TEMPLATE.md) — у находок
   есть идентификаторы (`S`/`C`/`T`/`A` + номер), по которым они трассируются
   в план и в коммит.
2. Строка отчёта добавляется в таблицу выше **сразу**, со статусом «открыт».
3. Когда находки закрыты — статус меняется здесь и в шапке самого отчёта.
   Расхождение между этими двумя местами означает, что учёт сломался.
4. Находка, которую решено не закрывать, переезжает в «Открытые находки» с
   причиной. Пустая строка причины не считается.
