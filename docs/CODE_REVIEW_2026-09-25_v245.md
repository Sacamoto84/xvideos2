## Summary of Passes (817–824)

### Pass 817 — `:feature-x` (`SavedX_Favorites.kt`)
- **Finding:** In `SavedX_Favorites.refresh()`, `favoriteIds.addAll(list.map { it.id })` allocated an intermediate `ArrayList<Long>` on the heap before adding IDs to the snapshot set.
- **Fix:** Replaced with direct iteration `for (item in list) { favoriteIds.add(item.id) }`, eliminating intermediate collection allocation.

### Pass 818 — `:feature-x` (`SavedX_History.kt`)
- **Finding:** `deleteBatch(items)` called `deleteBatchByIds(items.map { it.id })` without checking if `items` was empty, allocating an empty list. In `deleteBatchByIds`, `deletedIds` was initialized without initial capacity. In `refresh()`, empty history lists still triggered sorting and pruning cycles.
- **Fix:** Added `if (items.isEmpty()) return` in `deleteBatch`, pre-sized `HashSet<Long>(ids.size)` in `deleteBatchByIds`, and added `if (list.isEmpty()) return@withContext` in `refresh()`.

### Pass 819 — `:feature-x` (`SavedX_History.kt`)
- **Finding:** `pruneExcessItemsLocked()` called `list.removeAll(excess)` where `list` is a `SnapshotStateList`, performing $O(N \times M)$ scans over the entire list to remove excess items.
- **Fix:** Replaced with `while (list.size > MAX_HISTORY_ITEMS) { list.removeAt(list.lastIndex) }`, removing items directly from the tail in $O(1)$ per item.

### Pass 820 — `:feature-x` (`parseJson.kt`)
- **Finding:** `parseJson(json: String)` attempted JSON decoding on HTML error pages and non-object responses, catching exceptions and logging warnings in Timber.
- **Fix:** Added `val trimmed = json.trim(); if (trimmed.isEmpty() || !trimmed.startsWith('{')) return null` fast-path check.

### Pass 821 — `:feature-l` (`AlbumPicsDetails.kt`)
- **Finding:** In `retryFailedPages()`, `failedPages.map { it.page }.distinct().sorted()` created three sequential collections (list, set, sorted list).
- **Fix:** Replaced with single-pass `failedPages.mapTo(java.util.TreeSet<Int>()) { it.page }.toList()`, collecting distinct pages directly in natural sorted order.

### Pass 822 — `:feature-l` (`AlbumTopHits.kt`)
- **Finding:** If the repository returned a blank/empty response, passing it to `LJson.parseToJsonElement` threw an unexpected EOF serialization exception.
- **Fix:** Added `val raw = res.getOrNull().orEmpty(); if (raw.isBlank()) return@launch` before JSON parsing.

### Pass 823 — `:feature-x` (`CountryFlag.kt`)
- **Finding:** `getFlagEmoji(countryCode: String)` executed substring and uppercase transformations on empty or invalid single-character codes.
- **Fix:** Added early return `if (countryCode.length < 2) return "❓"`.

### Pass 824 — `:feature-l` (`getPicturesJson.kt`)
- **Finding:** `getPicturesJson(albumId, page)` built an in-memory JSON AST using `buildJsonObject` and `buildJsonArray` on every page request before serializing to string.
- **Fix:** Pre-escaped `LIST_ALBUM_PICTURES_QUERY_ESCAPED` and migrated to a direct templated JSON string without AST allocations.
