# Code Review & Optimization Report — Batch 34 (v250)

**Date:** 2026-09-25  
**Passes:** 857 – 864  
**Scope:** Network helpers, disk media resolver, M3U8 parser, video disk cache cleaner, profile and tag models, playback history model, and string formatting utilities.

---

### Pass 857 (`:core` — `NetworkIpHelper.kt`)
- **Finding:** `NetworkInterface.getNetworkInterfaces()` can return `null` on restricted environments or devices without network adapters, causing `Collections.list(null)` to throw a `NullPointerException`. Furthermore, interface names were converted to lowercase redundantly during sorting and priority checks.
- **Fix:** Used `NetworkInterface.getNetworkInterfaces()?.let { Collections.list(it) }.orEmpty()` and safe handling of `nif.inetAddresses`. Pre-evaluated interface priority once per item and guarded `buildServerUrl` against empty IP inputs.

---

### Pass 858 (`:core` — `LocalMediaResolver.kt`)
- **Finding:** `resolveVideo`, `resolvePoster`, and `resolveCollectionCover` called `section.lowercase()` repeatedly, allocating strings on every media request. In `isSafeInside`, canonical path comparison concatenated `baseCanonical + File.separator` even when the target was identical to base.
- **Fix:** Switched to allocation-free `section.equals("x", ignoreCase = true)` and `section.equals("r", ignoreCase = true)` branches. Added early `baseDir.exists()` guards in `resolveLMedia`, fast check in `encodePathSegment` for empty strings, and prioritized `fileCanonical == baseCanonical` in `isSafeInside`.

---

### Pass 859 (`:core` — `M3U8Helper.kt`)
- **Finding:** `parseM3U8Content` iterated through empty lines and ran full parsing even on invalid non-HLS text. When sorting `videoQualities` and deduplicating tracks, `sortedBy` and `distinctBy` allocated new collections even when lists contained 0 or 1 item.
- **Fix:** Added validation guard verifying `#EXTM3U` or `#EXT-X-` markers, skipped empty lines in `lineSequence()`, added single-element fast path to avoid sorting/deduplication allocations, and added `EMPTY` companion singleton and `isEmpty`/`isNotEmpty` properties to `M3U8Data`.

---

### Pass 860 (`:core` — `VideoDiskCacheCleaner.kt`)
- **Finding:** `appContext.cacheDir` was assumed non-null, and `deleteRecursively()` was invoked unconditionally even when cache directories did not exist, leading to redundant filesystem operations. Database deletion was not protected against I/O or locking exceptions.
- **Fix:** Added null and existence checks for `cacheDir`, checked `target.exists()` before calling `deleteRecursively()`, and wrapped database deletion in `runCatching`.

---

### Pass 861 (`:feature-l` — `UserProfile.kt`)
- **Finding:** `UserProfile` lacked fast verification properties and cached empty singleton, requiring manual blank checks at caller call sites.
- **Fix:** Added `isValid`, `isEmpty`, `isNotEmpty` properties, and a companion object `val EMPTY = UserProfile()`.

---

### Pass 862 (`:feature-r` — `TagsResponse.kt` & `RedApi.kt`)
- **Finding:** `TagsResponse` lacked convenience collection properties and `EMPTY` singleton. In `RedApi.kt`, `getTagSuggestions` did not trim query input and allowed querying blank strings over network.
- **Fix:** Added `isEmpty`, `isNotEmpty`, `size`, and `EMPTY` companion singleton to `TagsResponse`. Added trimming and empty query guard returning `Result.success(emptyList())` in `RedApi.getTagSuggestions`.

---

### Pass 863 (`:feature-x` — `XHistoryItem.kt`)
- **Finding:** `XHistoryItem` lacked fast boundary checks for remaining playback time, validation properties, and cached empty singleton. In `progressFraction`, unnecessary float divisions occurred when position was at or beyond total duration.
- **Fix:** Optimized `progressFraction` with boundary short-circuits (`1f` when completed or `lastPositionMs >= totalDurationMs`, `0f` when position or duration $\le 0$). Added `remainingMs`, `isValid`, `isEmpty`, `isNotEmpty` properties, and `EMPTY` companion singleton.

---

### Pass 864 (`:core` — `capitalizeEachWord.kt` & `toTwoDecimalPlacesWithColon.kt`)
- **Finding:** `capitalizeEachWord()` allocated a lowercase string and `StringBuilder` even for blank strings. `toTwoDecimalPlacesWithColon()` performed string formatting on every call for fractional digits between 0 and 99.
- **Fix:** Added fast return for blank strings in `capitalizeEachWord()`. Precomputed two-digit fraction strings array (`TWO_DIGIT_FRACS`) for values 00–99 in `toTwoDecimalPlacesWithColon()`.
