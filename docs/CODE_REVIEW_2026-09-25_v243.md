## Summary of Passes (801–808)

### Pass 801 — `:feature-x` (`parserItemVideo.kt`)
- **Finding:** In `parserItemVideo(document: Document)`, matching scripts called `it.data()` inside `firstOrNull { ... }` predicate and then called `.data()` a second time on the returned element. In Jsoup, `Element.data()` builds a string by traversing child `DataNode` nodes, incurring redundant allocations.
- **Fix:** Replaced with direct iterative loop `val data = script.data(); if (data.contains(PLAYER_MARKER)) return data`, evaluating `script.data()` exactly once per element.

### Pass 802 — `:feature-x` (`XSite.kt`)
- **Finding:** `normalizeXUrl(href: String)` performed `val trimmed = href.trim()` followed by `if (trimmed.isBlank())`. Since `trimmed` is already trimmed, iterating characters via `isBlank()` was redundant.
- **Fix:** Replaced with `if (trimmed.isEmpty()) return ""`.

### Pass 803 — `:feature-x` (`XSite.kt`)
- **Finding:** `extractXVideoId(href: String)` executed two complex regex engines (`NUMERIC_VIDEO_ID_REGEX` and `SLUG_VIDEO_ID_REGEX`) on every URL, even non-video URLs such as tags, channels, models, and homepage links.
- **Fix:** Added fast-path guard `if (href.isEmpty() || !href.contains("/video")) return null`, completely bypassing regex engines on non-video URLs.

### Pass 804 — `:feature-l` (`MediaCategoriesBootstrap.kt`)
- **Finding:** If the server or cache returned a blank response, passing it to `LJson.decodeFromString` triggered a serialization exception. Furthermore, updating `mediaCategoriesFlow.value` dispatched to `Dispatchers.Main` and notified flow collectors even if the categories had not changed.
- **Fix:** Added `if (raw.isBlank()) return` prior to JSON decoding, and added `if (mediaCategoriesFlow.value == newCategories) return` before switching to `Dispatchers.Main`.

### Pass 805 — `:core` (`toMD5.kt`)
- **Finding:** `String.toMD5()` instantiated a `MessageDigest` and allocated byte/char arrays even when hashing an empty string.
- **Fix:** Added precomputed constant `EMPTY_MD5 = "d41d8cd98f00b204e9800998ecf8427e"` and an early return `if (isEmpty()) return EMPTY_MD5`.

### Pass 806 — `:feature-r` (`R_Saved_Subscriptions.kt`)
- **Finding:** `add(item)` and `remove(username)` proceeded to dispatch IO operations even if `username` was blank. In `refreshSubscription()`, `res.distinctBy { it.id }` allocated a secondary `HashSet` and new `ArrayList` after iterating creators.
- **Fix:** Added `if (item.username.isBlank()) return` and `if (username.isBlank()) return` guards. In `refreshSubscription()`, deduplicated items into `seenIds` during ingestion, eliminating the `distinctBy` collection allocation.

### Pass 807 — `:core` (`SafePath.kt`)
- **Finding:** `normalizeRelativePath(raw: String)` performed `raw.replace('\\', '/').trim('/')` before verifying that the input was not blank, allocating strings on the heap even for empty/whitespace inputs.
- **Fix:** Added fast-fail `require(raw.isNotBlank()) { "Пустое имя пути" }` at the entry point prior to string manipulation.

### Pass 808 — `:feature-x` (`parserListVideo.kt`)
- **Finding:** `parseSiteCountryFlag(document: Document)` used `document.selectFirst("#site-localisation")`, parsing a CSS query instead of using direct ID lookup. Additionally, `href.isBlank()` in `parserListVideo` iterated characters despite `href` already being trimmed.
- **Fix:** Replaced with `document.getElementById("site-localisation")` and used `href.isEmpty()`.
