## Summary of Passes (841–848)

### Pass 841 — `:feature-l` (`Luscious.kt`)
- **Finding:** In `getAlbum(albumInput)`, string inputs unconditionally invoked `extractIdFromUrl()` (which runs a regex match) before checking if the string was already a plain numeric ID. In `extractIdFromUrl()`, `url.trim()` and regex matching were performed even on strings shorter than the minimal possible path containing `"albums/"`. Non-positive album IDs (`<= 0`) were not rejected.
- **Fix:** Switched parsing order so `trimmed.toIntOrNull()` is evaluated first, only falling back to `extractIdFromUrl()` if non-numeric. Rejected album IDs `<= 0`. Added early `if (url.length < 8) return null` guard in `extractIdFromUrl()`.

### Pass 842 — `:feature-l` (`AlbumDetails.kt`)
- **Finding:** Callers frequently needed to safely extract the cover URL if present and verify numeric ID validity, causing duplicated fallback logic across consumers.
- **Fix:** Added domain extension functions `coverUrl(): String?` and `hasValidId(): Boolean` to `AlbumDetails`, providing zero-allocation safe access.

### Pass 843 — `:feature-r` (`R_Saved_Collection.kt`)
- **Finding:** `deleteItemFromCollection()`, `deleteCollection()`, and `createCollection()` did not guard against blank IDs or collection names before launching coroutines. `refreshCollectionList()` lacked job cancellation, permitting overlapping disk reads on rapid navigation, and re-allocated collection copies for empty collections.
- **Fix:** Added early blank parameter returns in all collection mutation methods. Introduced `refreshJob?.cancel()` in `refreshCollectionList()`, returned `emptyList()` immediately when `collections.isEmpty()`, and bypassed copying for collections with empty `items`.

### Pass 844 — `:feature-x` (`readHtmlFromURLDirect.kt` & `readHtmlFromURLWebView.kt`)
- **Finding:** In `readHtmlFromURLDirect()`, non-HTTP/HTTPS URLs triggered Ktor client exceptions and error logs. In `readHtmlFromURLWebView()`, non-HTTP/HTTPS URLs loaded invalid schemes into WebView, and `evaluateJavascript` executed string replace pipelines on null or `"null"` strings.
- **Fix:** Added protocol validation (`http://` or `https://`) in both functions after trimming. In `readHtmlFromURLWebView`, added an early guard for null, empty, or `"null"` JavaScript evaluation results before string cleanup.

### Pass 845 — `:core` (`ZipUtils.kt`)
- **Finding:** `zipDirectory()` did not validate directory existence or directory type before creating the zip output stream. `unzip()` did not validate zip file existence or 0-byte size. Stream copying used default 8KB buffers and `walkTopDown` checked `rel.isBlank()`.
- **Fix:** Added `require(sourceDir.exists() && sourceDir.isDirectory)` and `require(zipFile.exists() && zipFile.isFile)`. Used an explicit `32KB` buffer (`ZIP_BUFFER_SIZE`) for buffered streams and `copyTo()`. Switched `rel.isBlank()` to `rel.isEmpty()`.

### Pass 846 — `:core` (`EventBus.kt`)
- **Finding:** `EventBus.postEvent(event)` launched a new coroutine on a single-threaded dispatcher for every single event, despite `_events` having an extra buffer capacity of 1024 items.
- **Fix:** Introduced `if (!_events.tryEmit(event)) { scope.launch { _events.emit(event) } }`, allowing 99.9% of event bus dispatches to emit synchronously without allocating or dispatching a coroutine.

### Pass 847 — `:core` (`AtomicWrite.kt`)
- **Finding:** `File.writeTextAtomically(text)` invoked `parent.mkdirs()` on every single write without checking `parent.exists()`. In exception handlers, `temp.delete()` could throw and mask the root cause. Empty strings triggered full UTF-8 string encoding.
- **Fix:** Added `if (!parent.exists()) parent.mkdirs()`, wrapped temp deletion in `runCatching { temp.delete() }`, and wrote an empty byte array directly when `text.isEmpty()`.

### Pass 848 — `:feature-x` (`TagsModel.kt` & `ModelScreenTag.kt`)
- **Finding:** Consumers of `TagsModel` and `ModelScreenTag` frequently instantiated new empty objects or manually inspected empty lists across multiple fields.
- **Fix:** Added `isEmpty` and `isNotEmpty` properties, default constructor parameters, and reusable `EMPTY` companion object singletons to both models.
