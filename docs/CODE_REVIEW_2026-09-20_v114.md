# Код-ревью: Итерация 135 (2026-09-20)

**Фокус ревью:** Завершение сквозной стабилизации навигации и паритета управления масштабированием (Zoom) между системными жестами и наэкранными кнопками «Назад»: приоритетное закрытие `LPictureInfoDialog` в `L_FullScreenImage`, возврат к началу списка по «Назад» в `L_ScreenAlbumSearch`, паритет сброса зума в наэкранном оверлее `RedFullScreenOverlay` и `ScreenRedFullScreen`, приоритетный сброс зума в ландшафтном полноэкранном режиме плеера `ScreenX_VideoPlayer`.

---

## 1. Контекст и цели

1. **[NAV04] Приоритетное закрытие диалога информации `LPictureInfoDialog` в `L_FullScreenImage` (`:feature-l`)**:
   - В полноэкранном просмотрщике L-раздела (`L_FullScreenImage.kt`) диалог метаданных `LPictureInfoDialog` открывался по нажатию кнопки Info (`showInfoDialog = true`).
   - Однако в цепочке `BackHandler` отсутствовала проверка состояния `showInfoDialog`. При открытом поверх контента диалоге нажатие системной кнопки «Назад» приводило к выходу из режима полного экрана или полному закрытию экрана (`isClosing = true`), минуя естественное закрытие поверхностного диалога.
   - *Решение:*
     - Добавлен приоритетный `BackHandler(enabled = showInfoDialog) { showInfoDialog = false }`.
     - Все последующие обработчики (`isCurrentPageZoomed`, `isFullScreen`, `isClosing`) дополнены условием `!showInfoDialog`.

2. **[NAV05] Пошаговый возврат к началу списка по кнопке «Назад» в `L_ScreenAlbumSearch` (`:feature-l`)**:
   - В экране поиска альбомов `L_ScreenAlbumSearch.kt` присутствовал только один обработчик: `BackHandler(enabled = searchText.isNotEmpty()) { vm.searchText.value = "" }`.
   - Если строка поиска пуста или очищена, но пользователь прокрутил список категорий и результатов вниз (`vm.state.firstVisibleItemIndex > 0`), нажатие «Назад» сразу закрывало экран поиска.
   - *Решение:*
     - Добавлен иерархический возврат: `BackHandler(enabled = searchText.isEmpty() && vm.state.firstVisibleItemIndex > 0) { coroutineScope.launch { vm.state.animateScrollToItem(0) } }`.

3. **[NAV06] Паритет наэкранной кнопки «Назад» и системного жеста в `ScreenRedFullScreen` (`:feature-r`)**:
   - В полноэкранном плеере Red (`ScreenRedFullScreen.kt`) системный `BackHandler` корректно сбрасывал увеличение кадра (`resetZoomTrigger++`), если видео было увеличено (`isCurrentPageZoomed` / `isZoomed`).
   - Однако в `RedFullScreenOverlay.kt` наэкранная стрелка «Назад» напрямую вызывала `navigator.pop()`, приводя к неконсистентному закрытию экрана в приближенном состоянии при клике на стрелку.
   - *Решение:*
     - В `RedFullScreenOverlay` добавлен параметр `onBack: () -> Unit = { navigator.pop() }`, привязанный к `IconButton(onClick = onBack)`.
     - В `RedFullScreenPage` проброшен коллбэк `onBack`, который в ленте `RedFullScreenFeed` и в одиночном плеере `RedFullScreenSingle` сначала плавно сбрасывает зум до 1.0x и только при исходном масштабе закрывает плеер.

4. **[NAV07] Приоритет сброса зума в ландшафтном режиме `ScreenX_VideoPlayer` (`:feature-x`)**:
   - В видеоплеере X (`ScreenX_VideoPlayer.kt`) при активном ландшафтном полноэкранном режиме (`vm.isFullScreen == true`) системный `BackHandler(enabled = vm.isFullScreen)` безусловно вызывал `vm.exitFullScreen()`, а наэкранная кнопка в оверлее также сначала выходила из полноэкранного режима вместо сброса зума.
   - *Решение:*
     - Обработчик зума в `VideoPlayerContentView` активирован для всех режимов: `BackHandler(enabled = isZoomed) { resetZoomTrigger++ }`.
     - Обработчик выхода из плеера: `BackHandler(enabled = !isZoomed && !vm.isFullScreen) { navigator.pop() }`.
     - В наэкранной кнопке возврата оверлея проверка приближения вынесена на первое место: `if (isZoomed) resetZoomTrigger++ else if (vm.isFullScreen) vm.exitFullScreen() else navigator.pop()`.

## 2. Выявленные замечания и исправления

### [NAV04] Иерархия закрытия диалога LPictureInfoDialog в L_FullScreenImage
- **Проблема:** В [L_FullScreenImage.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenFullScreen/L_FullScreenImage.kt) нажатие «Назад» при открытом окне информации закрывало просмотрщик вместо скрытия диалога.
- **Решение:** Внедрён первоочередной `BackHandler(enabled = showInfoDialog) { showInfoDialog = false }`.
- **Статус:** Исправлено.

### [NAV05] Двухэтапная навигация в L_ScreenAlbumSearch
- **Проблема:** В [L_ScreenAlbumSearch.kt](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/explorer/tab/albumSearch/L_ScreenAlbumSearch.kt) прокрученный список закрывался без промежуточного возврата к началу.
- **Решение:** Добавлен скролл к первому элементу списка по нажатию «Назад».
- **Статус:** Исправлено.

### [NAV06] Паритет зума в RedFullScreenOverlay
- **Проблема:** В [RedFullScreenOverlay.kt](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/fullscreen/RedFullScreenOverlay.kt) наэкранная стрелка не сбрасывала масштаб.
- **Решение:** Проброшен унифицированный `onBack` с поддержкой `resetZoomTrigger`.
- **Статус:** Исправлено.

### [NAV07] Сброс масштаба в полноэкранном плеере ScreenX_VideoPlayer
- **Проблема:** В [ScreenX_VideoPlayer.kt](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/videoplayer/ScreenX_VideoPlayer.kt) в ландшафтном режиме увеличение кадра сбрасывалось только вместе с выходом из полноэкранного режима.
- **Решение:** Обработчики системной кнопки и наэкранной стрелки переведены на первоочередной сброс зума.
- **Статус:** Исправлено.
