## Находки

### C1 — ScreenAlbumList: Отсутствие проверки `stateGrid.isScrolled` в кнопке тулбара `onBackClick`. Средняя.

[feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbumList/ScreenAlbumList.kt:233-243](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbumList/ScreenAlbumList.kt#L233-L243)

В `ScreenAlbumListContent` системный `BackHandler` корректно обрабатывал цепочку возврата: при наличии открытого диалога фильтрации закрывал его, при прокрученной сетке (`isGridScrolled`) плавно возвращал к нулевому элементу, при нахождении на странице пейджера > 0 плавно возвращал на страницу 0, и только затем закрывал экран. Однако кнопка «Назад» в тулбаре (`onBackClick`) проверяла только `vm.statePager.currentPage > 0` и сразу вызывала `navigator.pop()`, полностью игнорируя факт скролла сетки альбомов. При клике на стрелку в шапке пользователь мгновенно вылетал из экрана вместо прокрутки к началу.

**Решение:**
1. Внедрены `AlbumListBackAction` и чистая функция `resolveAlbumListBackAction(showFilterDialog, isGridScrolled, currentPage)`.
2. В `onBackClick` сетки `AlbumListPageGrid` подключено разрешение действия через `resolveAlbumListBackAction(showFilterDialog, stateGrid.isScrolled, vm.statePager.currentPage)`, что гарантирует идентичность поведения системного жеста и экранной кнопки.
3. В `LPureFunctionsTest.kt` добавлен модульный тест на все сценарии приоритетов возврата.

### C2 — ScreenTags: Отсутствие проверки `isScrolled` в кнопке тулбара `ScreenTags`. Средняя.

[feature-x/src/main/java/com/client/xvideos/x/screens/tags/ScreenTags.kt:75-81](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/tags/ScreenTags.kt#L75-L81)
[feature-x/src/main/java/com/client/xvideos/x/screens/tags/atom/TagsPaginatedListScreen.kt:55-75](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/tags/atom/TagsPaginatedListScreen.kt#L55-L75)

В `TagsPaginatedListScreen` локально создавался `val listState = rememberLazyListState()` и регистрировался внутренний `BackHandler(enabled = isScrolled)`. В то же время родительский `ScreenTags` не имел доступа к состоянию скролла списков страниц пейджера, из-за чего клик по стрелке «Назад» в `topBar` тулбара сразу анимировал пейджер на страницу 0 либо вызывал `navigator.pop()`, пропуская прокрутку списка к началу.

**Решение:**
1. В `TagsPaginatedListScreen` добавлен параметр `listState: LazyListState = rememberLazyListState()`.
2. В `ScreenTags` вынесено хранение состояний страниц `listStates = remember { mutableStateMapOf<Int, LazyListState>() }`, передаваемое в дочерние списки.
3. Внедрены `TagsBackAction` и `resolveTagsBackAction(isListScrolled, currentPage)`. В кнопке «Назад» тулбара теперь проверяется `currentListState?.isScrolled == true` и при необходимости выполняется `animateScrollToItem(0)`.
4. В модуле `:feature-x` создан тест `TagsBackActionTest.kt` для проверки приоритетов возврата.

### C3 — XlrBackupManager: Защита от включения скрытых и временных служебных каталогов (`.xlr_old_*` и `.*`). Низкая.

[core/src/main/java/com/client/xvideos/common/backup/XlrBackupManager.kt:61-90, 330-345, 504-525](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/backup/XlrBackupManager.kt#L61-L90)

При сбоях восстановления базы данных в хранилище могут оставаться служебные каталоги вида `.xlr_old_*`. Функция `currentBackupItems()` сканировала корневые каталоги и включала любые директории без фильтрации скрытых папок, из-за чего в настройках бэкапа могли появляться мусорные элементы. Кроме того, `shouldIncludeBackupEntry()` не отфильтровывала пути с точкой, а `writeDirectory()` добавляла каталоги в архив до проверки фильтрации.

**Решение:**
1. В `currentBackupItems()` добавлен параметр `baseDir: File = AppPath.main` (для изолированного тестирования) и фильтр `!it.name.startsWith(".")`.
2. В `shouldIncludeBackupEntry()` добавлена проверка `normalized.split('/').any { it.startsWith(".") }`, исключающая скрытые папки и файлы из бэкапа и расчёта размера.
3. В `writeDirectory()` проверка `shouldIncludeBackupEntry` вынесена перед записью директории в zip.
4. В `XlrRestoreApplyTest.kt` добавлены тесты на фильтрацию `.xlr_old_*` и скрытых путей в `shouldIncludeBackupEntry` и `currentBackupItems`.
