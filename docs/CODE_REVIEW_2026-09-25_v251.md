# Code Review & Optimization Report — Batch 35 (v251)

**Date:** 2026-09-25  
**Passes:** 865 – 872  
**Scope:** Core context and build state holders, backup domain models, download work managers and states, storage cleanup gate, network connectivity observers, network traffic models, and video player configuration models.

---

### Pass 865 (`:core` — `AppContextHolder.kt` & `AppBuildInfo.kt`)
- **Finding:** Accessing `AppContextHolder.applicationContext` before initialization throws `IllegalArgumentException`, which limits safe queries in test setups and background workers. `AppBuildInfo` had no simple inquiry property to determine if build metadata was supplied.
- **Fix:** Added `isInitialized: Boolean` and `getOrNull(): Context?` to `AppContextHolder`. Added `isInitialized: Boolean` to `AppBuildInfo`.

---

### Pass 866 (`:core` — `XlrBackupModels.kt`)
- **Finding:** `XlrBackupReport` and `XlrBackupItem` lacked default parameter values, emptiness verification properties, and cached empty singletons. `XlrBackupOptions` lacked convenience properties to detect full vs. mini backup modes.
- **Fix:** Added default arguments, `isEmpty`, `isNotEmpty` properties, and `EMPTY` companion object to `XlrBackupReport`. Added `isFullBackup`, `isMiniBackup`, and `DEFAULT`, `FULL`, `MINI` companion instances to `XlrBackupOptions`.

---

### Pass 867 (`:core` — `DownloadWorkState.kt`)
- **Finding:** `DownloadWorkState` callers had to manually query status enums and perform percentage/fraction calculations. `isFinished` used multiple logical `||` operators.
- **Fix:** Refactored `isFinished` to pattern-match `when(status)`, added `isRunning`, `isSuccessful`, `isFailed`, `isCancelled` helper properties, and introduced `progressFraction: Float` for unified progress indicator bindings.

---

### Pass 868 (`:core` — `WorkDownloadManager.kt`)
- **Finding:** `cancelByTag(tag)` and `observeDownloadsByTag(tag)` did not validate or trim tag inputs, allowing blank tag searches. Mapping work info lists triggered list allocations even when empty.
- **Fix:** Added input trimming and early blank returns. Avoided `.map` transformations when query result lists are empty (`if (list.isEmpty()) emptyList() else ...`).

---

### Pass 869 (`:core` — `StorageCleanupGate.kt`)
- **Finding:** `await()` unconditionally called `job?.join()`, invoking coroutine suspension overhead even if the cleanup job was already completed or had not started.
- **Fix:** Added `isStarted`, `isCompleted`, and `isActive` state properties. Optimized `await()` to join only if `currentJob != null && currentJob.isActive`.

---

### Pass 870 (`:core` — `AndroidConnectivityObserver.kt`)
- **Finding:** In `unregisterNetworkCallback()`, `networkCallback` was cleared after unregistering, leaving a theoretical window where concurrent scope cancellation or callbacks could invoke unregister twice.
- **Fix:** Atomically captured and set `networkCallback = null` prior to unregistering with `ConnectivityManager`.

---

### Pass 871 (`:core` — `NetworkTrafficMonitor.kt`)
- **Finding:** `TrafficData` lacked combined session and overall traffic calculation properties, forcing UI components to compute sums redundantly.
- **Fix:** Added `totalSessionTraffic`, `totalOverallTraffic`, `isIdle` properties, and companion singletons `EMPTY` and `UNSUPPORTED`.

---

### Pass 872 (`:core` — `PlayerPlaybackConfig.kt`)
- **Finding:** `PlayerPlaybackConfig` required `url` to be specified explicitly with no default, lacked validation helpers and empty singleton. `PlayerPlaybackCallbacks` lacked a cached empty default instance.
- **Fix:** Added default parameter `url = ""` with `isValid`, `isEmpty`, `isNotEmpty` properties and `EMPTY` companion object to `PlayerPlaybackConfig`. Added `EMPTY` companion object to `PlayerPlaybackCallbacks`.
