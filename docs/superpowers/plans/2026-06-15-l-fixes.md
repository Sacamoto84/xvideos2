# L module — three UI fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix three independent L-section UI bugs — album-list scroll position lost on return, duplicate "scroll to top" FAB on the album screen, and the Lavender dialog confirm button not being a 50% pill.

**Architecture:** Three isolated, minimal edits. Issue 1 wires an existing-but-unused ScreenModel scroll map into the grid. Issue 2 removes a duplicate Scaffold FAB (keeping the shared one) and deletes the now-dead helper. Issue 3 flips a theme constant from `Float` (px overload) to `Int` (percent overload) so the shared dialog button becomes a pill. No shared state between the three.

**Tech Stack:** Kotlin, Jetpack Compose, Voyager (ScreenModel navigation), Hilt.

**Spec:** `docs/superpowers/specs/2026-06-15-l-fixes-design.md`

**Testing note:** No UI test harness exists in this project, and these Compose changes are not unit-testable. Verification per task = compile via Gradle + manual/`@Preview` check. Each commit stages ONLY the files it touches (the working tree has unrelated in-progress changes — do not stage them).

Build command (Windows PowerShell):
```
.\gradlew.bat assembleDebug
```
(Unix: `./gradlew assembleDebug`)

### Task 3: Issue 3 — Lavender dialog confirm button = 50% pill

**Files:**
- Modify: `app/src/main/java/com/client/xvideos/common/theme/Theme.kt:57`

Background: `LavenderDialog.kt:99` uses `RoundedCornerShape(d.buttonBorderRadius)`. `buttonBorderRadius` is `50f` (`Float`), which selects `RoundedCornerShape(size: Float)` = 50 **pixels**, not 50 percent. Changing the constant to `Int` selects `RoundedCornerShape(percent: Int)` = 50% = pill. All Lavender dialogs route through `LavenderDialog`, so this one edit fixes all of them. `buttonBorderRadius` is referenced nowhere except `Theme.kt` and `LavenderDialog.kt`.

- [ ] **Step 1: Change the constant from Float to Int**

In `Theme.kt`, replace line 57:

```kotlin
        const val buttonBorderRadius = 50f //Радиус границы кнопки
```

with:

```kotlin
        const val buttonBorderRadius = 50 // Радиус кнопки в процентах (50% = полукруг/pill)
```

No change needed at `LavenderDialog.kt:99` — `RoundedCornerShape(d.buttonBorderRadius)` now resolves to the `Int` percent overload automatically.

- [ ] **Step 2: Compile**

Run: `.\gradlew.bat assembleDebug`
Expected: BUILD SUCCESSFUL. No type error at `LavenderDialog.kt:99` (the `Int` overload `RoundedCornerShape(percent: Int)` exists).

- [ ] **Step 3: Manual / preview verify**

Open `LavenderDialog.kt` `@Preview` (`LavenderDialogPreview`) in the IDE, or run the app and trigger a Lavender dialog (e.g. delete album → `AlbumDialogDeleteAlbum`).
Expected: the confirm button ("Удалить") is a full pill (fully rounded ends), not a small ~16dp rounded rectangle.

- [ ] **Step 4: Commit**

```
git add app/src/main/java/com/client/xvideos/common/theme/Theme.kt
git commit -m "fix(L): Lavender dialog confirm button as 50% pill (percent radius)"
```
