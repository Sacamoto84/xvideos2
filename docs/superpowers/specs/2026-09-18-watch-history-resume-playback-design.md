# Спецификация: История просмотров с функцией «Продолжить просмотр»

Дата: 18.09.2026. Согласовано в рамках сессии Brainstorming.

---

## 1. Понимание задачи (Understanding Summary)

* **Что создаётся:** 
  * Подсистема «История просмотров» для раздела **X (xvideos)**.
  * Функция «Продолжить просмотр»: сохранение позиции воспроизведения для роликов длительностью более 2 минут (как при онлайн-просмотре, так и для скачанных локально файлов X).
  * Экран «История» в качестве 3-й подвкладки внутри панели `Savable` раздела X (рядом с «Избранное» и «Скачанное»).
  * Автоматическое возобновление воспроизведения с сохранённой позиции при открытии видео, сопровождаемое плашкой/снекбаром с возможностью в 1 клик начать «С начала».
  * Индикация прогресса (полоса просмотренного / отметка о завершении) на карточках видео в истории.
* **Где размещается:**
  * UI: `ScreenXDashBoards` (подвкладка `История`), новый экран `ScreenXHistory`.
  * Плеер: онлайн-плеер `ScreenX_VideoPlayer` / `ScreenX_VideoPlayerSM` и локальный плеер `ScreenX_LocalVideoPlayer`.
  * Хранилище: `AppPath.x_history` (`filesDir/store/X/History`), репозиторий `SavedX_History` внутри `SavedX`.
* **Для чего:** Дать пользователю возможность легко возвращаться к длинным видеороликам, не теряя место остановки, и просматривать ленту недавно открытых видео.
* **Для кого:** Пользователи раздела X, смотрящие ролики длительностью от 2 минут.
* **Ключевые ограничения:**
  * Ролики короче 2 минут (120 секунд) не сохраняют позицию возобновления.
  * Если ролик досмотрен более чем на 90–95% (или завершился), он остаётся в истории, но позиция сбрасывается на 0:00 (следующий запуск начнётся с начала).
  * Ёмкость хранилища: максимум 200 записей (ротация по принципу FIFO на основе времени последнего просмотра `updatedAt`).
  * Управление записями: возможность удалить отдельный ролик из истории и кнопка «Очистить всё» с подтверждением.
  * Хранение: изолированные файлы во внутренней памяти (`filesDir/store/X/History`), защищённые код-паролем приложения и входящие в ZIP-бэкап.
* **Явные non-goals:**
  * Не затрагивает разделы R (RedGifs) и L (Luscious).
  * Не требует авторизации и не синхронизируется с внешними серверами xvideos.
  * Не передаётся по P2P-синхронизации (на первом этапе).

## 2. Предположения (Assumptions)

1. **Минимальный порог фиксации:** Позиция фиксируется только после того, как пользователь посмотрел хотя бы 5 секунд ролика (случайные быстрые открытия не перезаписывают позицию).
2. **Периодичность сохранения:** Сохранение позиции на диск происходит в корутине на `Dispatchers.IO` каждые 5 секунд во время воспроизведения, а также принудительно при нажатии на паузу и при уходе с экрана (`onDispose`).
3. **Единый идентификатор:** Синхронизация между онлайн-просмотром и скачанным файлом происходит по общему `id` видео (числовой идентификатор xvideos).
4. **Хранилище:** Используется проектный механизм `FileDB<XHistoryItem>`, гарантирующий атомарность записи (`writeTextAtomically`) и потокобезопасность.
5. **UI плашки «С начала»:** Плашка появляется внизу плеера над панелью управления, скрывается автоматически через 4 секунды или при клике пользователем на «С начала» / перемотке.

## 3. Журнал решений (Decision Log)

| # | Решение | Выбранный вариант | Альтернативы | Обоснование |
|---|---------|-------------------|--------------|-------------|

| **D2** | Расположение экрана Истории | 3-я подвкладка в панели `Savable` раздела X | Отдельный пункт в `MenuScreen` / кнопка в верхнем баре | Органично дополняет вкладки «Избранное» и «Скачанное», не перегружая корневую навигацию. |
| **D3** | Механизм возобновления | Автоматический старт с сохранённой позиции + плашка «С начала» | Модальный диалог перед стартом / ручной клик | Мгновенный старт без лишних действий со стороны пользователя и простота сброса в 1 клик. |
| **D4** | Поведение при досмотре (>90–95%) | Сохранение ролика в истории со сбросом позиции на 0:00 | Полное удаление из истории / сохранение до последней секунды | Ролик остаётся доступен в списке просмотренных, но повторный запуск начнётся с начала. |
| **D5** | Правила хранения и ёмкость | До 200 записей (FIFO), удаление отдельных записей + «Очистить всё» | Безлимитное хранение / только полная очистка | Оптимальный расход памяти и диска устройства при сохранении гибкости управления. |

## 4. Архитектура и финальный дизайн

### 4.1. Модель данных `XHistoryItem`
Файл: `feature-x/src/main/java/com/client/xvideos/x/model/XHistoryItem.kt`

```kotlin
package com.client.xvideos.x.model

import androidx.compose.runtime.Immutable
import kotlinx.serialization.Serializable

@Immutable
@Serializable
data class XHistoryItem(
    val item: ItemsX = ItemsX(),
    val lastPositionMs: Long = 0L,
    val totalDurationMs: Long = 0L,
    val updatedAt: Long = 0L,
) {
    /** Ролик подходит для возобновления: длина >= 2 мин, просмотрено > 5 сек и < 95% длины */
    val isEligibleForResume: Boolean
        get() = totalDurationMs >= 120_000L &&
                lastPositionMs > 5_000L &&
                lastPositionMs < (totalDurationMs * 0.95)

    /** Доля просмотренного для полосы прогресса (0.0 .. 1.0) */
    val progressFraction: Float
        get() = if (totalDurationMs > 0L) (lastPositionMs.toFloat() / totalDurationMs).coerceIn(0f, 1f) else 0f
}
```

### 4.2. Пути хранилища `AppPath`
Файл: `core/src/main/java/com/client/xvideos/common/AppPath.kt`

* Добавляется путь `x_history`:
  ```kotlin
  val x_history: String get() = "$main/${Folder.X.value}/History"
  ```
* В `init(context: Context)` добавляется:
  ```kotlin

  ```

### 4.3. Репозиторий `SavedX_History`
Файл: `feature-x/src/main/java/com/client/xvideos/x/feature/saved/SavedX_History.kt`

* Подключается в `SavedX`: `val history = SavedX_History(scope)`.
* Внутреннее хранилище: `FileDB<XHistoryItem>(AppPath.x_history, "XHistoryItem", XHistoryItem.serializer())`.
* Реактивный список: `val list = historyDb.list` (отсортирован по убыванию `updatedAt`).
* Ключевые методы:
  * `updateProgress(item: ItemsX, positionMs: Long, durationMs: Long)`:
    * Проверяет, если `positionMs >= durationMs * 0.95` -> сохраняет `lastPositionMs = 0L`.
    * Иначе, если `durationMs >= 120_000L && positionMs >= 5_000L` -> сохраняет актуальную позицию.
    * Пишет атомарно на `Dispatchers.IO`.
    * Выполняет ротацию FIFO: если `list.size > 200`, удаляет самые старые записи.
  * `get(id: Long): XHistoryItem?`: получение сохранённого элемента.
  * `delete(id: Long)`: удаление одного файла истории.
  * `clearAll()`: удаление всех файлов истории.

### 4.4. Интеграция с плеерами

#### Онлайн-плеер `ScreenX_VideoPlayer` / `ScreenX_VideoPlayerSM`
* При загрузке и старте HLS-потока запрашивается `history.get(videoId)`.
* Если `historyItem.isEligibleForResume == true`:
  * Передаётся `startTimeInSeconds = (historyItem.lastPositionMs / 1000f)` в `MediaPlayerHost`.
  * Устанавливается флаг `showResumePill = true` с текстом таймкода (`"Возобновлено с MM:SS"`).
* В UI оверлея плеера:
  * Отображается плашка: `Возобновлено с MM:SS | [С начала]`
  * Клик на `[С начала]` выполняет `host.seekToTime = 0f` и убирает плашку.
  * Авто-скрытие плашки через 4 секунды.
* Периодический трекинг:
  * Корутина раз в 5 секунд при активном воспроизведении вызывает `history.updateProgress(item, host.currentTime * 1000, host.totalTime * 1000)`.
  * При паузе и в `onDispose` выполняется финальный сброс позиции.

#### Локальный плеер `ScreenX_LocalVideoPlayer`
* Аналогичный трекинг позиции по `id` ролика через `SavedX_History` для скачанных файлов.

### 4.5. Пользовательский интерфейс `ScreenXHistory`
Файл: `feature-x/src/main/java/com/client/xvideos/x/screens/history/ScreenXHistory.kt`

* **Вкладка в `ScreenXDashBoards`**:
  * В `savedTabs` добавляется иконка `Icons.Outlined.History` (индекс 2).
  * Контент переключается на `ScreenXHistory`.
* **Элементы экрана**:
  * Верхняя панель: Заголовок «История», количество роликов, иконка корзины «Очистить всё» (с `AlertDialog` подтверждения).
  * Сетка карточек: превью с бейджем длительности, снизу превью тонкая полоса `LinearProgressIndicator` красного цвета, отображающая процент просмотренного.
  * Контекстное меню (три точки): «Удалить из истории», «В избранное», «Скачать» / «В галерею».
  * Empty State: при пустом списке — аккуратная иконка и текст «История просмотров пуста».

1. **Юнит-тесты**:
   * `XHistoryItemTest`: сериализация, десериализация, проверка логики `isEligibleForResume` и `progressFraction`.

2. **Архитектурные тесты**:
   * Запуск `ModuleBoundariesTest` и `LayerBoundariesTest` — 100% прохождение без нарушений.
   * `detekt` и `lintDebug` без новых предупреждений и ошибок.
