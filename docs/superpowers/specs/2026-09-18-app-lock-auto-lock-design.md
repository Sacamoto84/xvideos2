# Спецификация: Автоблокировка приложения по таймеру неактивности в фоне

Составлено 18.09.2026. Согласовано с пользователем.

---

## 1. Понимание задачи (Understanding Summary)

* **Что создаётся:** Автоблокировка приложения по истечении заданного времени нахождения в фоне (сворачивание или выключение экрана устройства).
* **Для чего:** Повышение приватности. До этой доработки замок взводился только при холодном старте через `SplashActivity`, а при возврате через диспетчер задач («Недавние») приложение оставалось открытым неограниченное время.
* **Для кого:** Пользователи, у которых активирован код доступа приложения (App Lock) или маскировка под «Калькулятор».
* **Настройки:** Возможность выбора времени в меню настроек приватности:
  * «Сразу» (0 секунд) — блокировка при любом сворачивании;
  * «30 секунд»;
  * «1 минута» *(по умолчанию)*;
  * «5 минут»;
  * «Никогда» — возврат к прежнему поведению (замок только при холодном перезапуске).
* **Ограничения:**
  * Никаких блокировок при активном экране (чтение, листание, просмотр видео).
  * Нулевое потребление батареи в фоне (пассивный замер через монотонные часы, без фоновых служб).
* **Явные non-goals:**
  * Отслеживание отсутствия касаний экрана в активном состоянии.
  * Сторонние фоновые сервисы и воркеры.

---

## 2. Предположения (Assumptions)

1. **Расположение:** Пункт настройки таймера находится в `AppLockSettingsSection` раздела «Настройки» -> «Приватность» и отображается только при включённой блокировке приложения (`enabled == true`).
2. **Точки фиксации жизненного цикла:** Уход в фон фиксируется через `ProcessLifecycleOwner` по событию `ON_STOP`, а проверка истечения таймаута — по событию `ON_START`.
3. **Монотонные часы:** Измерение интервала проводится исключительно через `SystemClock.elapsedRealtime()`, что защищает приложение от манипуляций с системным временем.
4. **Маскировка под калькулятор:** Автоблокировка прозрачно совместима с режимом камуфляжа — при возврате из фона после таймаута отображается экран калькулятора, сохраняя текущий открытый экран под ним.
5. **Сохранение:** Значение таймаута (в секундах) сохраняется в `Settings.kt` через `SettingElementInt`.

## 4. Финальный дизайн (Final Design)

### 4.1. Модуль `:core`

#### Модель данных `AppLockTimeout`
Файл: `core/src/main/java/com/client/xvideos/common/applock/AppLockTimeout.kt`

```kotlin
package com.client.xvideos.common.applock

enum class AppLockTimeout(
    val seconds: Int,
    val displayName: String
) {
    IMMEDIATELY(0, "Сразу"),
    SECONDS_30(30, "30 секунд"),
    MINUTES_1(60, "1 минута"),
    MINUTES_5(300, "5 минут"),
    NEVER(-1, "Никогда");

    val durationMillis: Long
        get() = if (seconds <= 0) 0L else seconds * 1000L

    companion object {
        val DEFAULT = MINUTES_1

        fun fromSeconds(seconds: Int): AppLockTimeout =
            entries.firstOrNull { it.seconds == seconds } ?: DEFAULT
    }
}
```

#### Настройки `Settings.kt`
Файл: `core/src/main/java/com/client/xvideos/common/settings/Settings.kt`

Добавление настройки:
```kotlin
/**
 * Время нахождения в фоне (в секундах) до автоматической блокировки приложения.
 * 0 — сразу, -1 — никогда (только при перезапуске).
 */
val app_lock_timeout_seconds by lazy {
    SettingElementInt(pref, "app_lock_timeout_seconds", AppLockTimeout.DEFAULT.seconds)
}
```

#### Обновление `AppLockSession.kt`
Файл: `core/src/main/java/com/client/xvideos/common/applock/AppLockSession.kt`

* Добавление полей:
  * `@Volatile private var lastBackgroundElapsedMs: Long = 0L`
* Методы:
  * `onAppBackgrounded()`: запоминает `SystemClock.elapsedRealtime()`.
  * `onAppForegrounded(timeoutSeconds: Int, isLockConfigured: Boolean)`: проверяет дельту и вызывает `lock()`, если истёк таймаут.

#### Наблюдатель жизненного цикла `AppLockLifecycleObserver`
Файл: `core/src/main/java/com/client/xvideos/common/applock/AppLockLifecycleObserver.kt`

* Реализует `DefaultLifecycleObserver`.
* В `onStop(owner: LifecycleOwner)`: фиксирует уход в фон. При таймауте `IMMEDIATELY` сразу вызывает `lock()`.
* В `onStart(owner: LifecycleOwner)`: проверяет дельту времени и при необходимости блокирует сессию.
* Регистрируется в `App.onCreate()` через `ProcessLifecycleOwner.get().lifecycle.addObserver(...)`.

### 4.2. Модуль `:app`

#### Экран настроек `AppLockSection.kt`
Файл: `app/src/main/java/com/client/xvideos/screenSettings/components/AppLockSection.kt`

* Если `enabled == true`, отображается строка настройки автоблокировки:
  * Текст: «Автоблокировка»
  * Подзаголовок: например, «Через 1 минуту в фоне», «Сразу при выходе» или «Выключена (только при запуске)»
  * По клику открывается `AppLockTimeoutDialog`.
* Компонент `AppLockTimeoutDialog`:
  * Построен на базе `LavenderDialog`.
  * Отображает радиокнопки для всех пяти вариантов `AppLockTimeout.entries`.
  * При клике на вариант вызывает `Settings.app_lock_timeout_seconds.setValue(...)` и закрывает диалог.

### 4.3. Обработка граничных случаев (Edge Cases)

1. **Process Death / вытеснение памяти:** ОС убивает процесс $\rightarrow$ новый запуск через `SplashActivity` $\rightarrow$ сессия изначально заблокирована (`unlocked = false`), безопасность не нарушается.
2. **Перевод часов:** Использование `SystemClock.elapsedRealtime()` защищает от смены времени/часовых поясов.
3. **Режим калькулятора:** При блокировке сессии `MainActivity` отображает калькулятор. После верного PIN восстанавливается прежний стек экранов.
4. **Быстрое сворачивание:** Превью в «Недавних» защищено через существующий `FLAG_SECURE` (`blur_recent_tasks`).

### 4.4. План тестирования

* **Unit-тесты в `:core` (`AppLockTimeoutTest` и `AppLockSessionTest`):**
  * Корректный парсинг `fromSeconds()` для всех значений и некорректных чисел.
  * Тест `onAppBackgrounded` / `onAppForegrounded`:
    * Разница во времени меньше таймаута $\rightarrow$ сессия остаётся разблокированной.
    * Разница во времени $\ge$ таймаута $\rightarrow$ сессия блокируется.
    * Для `IMMEDIATELY` $\rightarrow$ мгновенная блокировка.
    * Для `NEVER` $\rightarrow$ отсутствие блокировки.
    * Если блокировка отключена в настройках $\rightarrow$ замок не взводится.
* **Ручное тестирование в приложении:**
  * Проверка таймера 30 сек и 1 мин при сворачивании.
  * Проверка переключения режимов в окне настроек.
  * Проверка связки с калькулятором.
