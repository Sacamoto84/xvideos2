## Summary of Passes (833–840)

### Pass 833 — `:core` (`CollectionDB.kt`)
- **Finding:** In `create(collectionName)`, an invalid collection name returned `IOException` rather than domain input exception `IllegalArgumentException`. In `readAllCollections()`, empty directories allocated a full `ArrayList` and invoked `sortBy`, even when zero or one element was present. In `loadCollectionDir()`, empty folders allocated a full `ArrayList` and triggered `sortByDescending`.
- **Fix:** Switched invalid name failure to `IllegalArgumentException` (consistent with `unsafeItemName`). Added early returns `if (entries.isEmpty()) return@synchronized emptyList()` and `if (rawFiles.isEmpty()) return CollectionEntity(...)`. Guarded sorting with `if (result.size > 1)` and `if (collectionFiles.size > 1)`.

### Pass 834 — `:core` (`GallerySaver.kt`)
- **Finding:** In `saveLocal()` and `saveFromUrl()`, `File(fileName.trim()).name.trim()` allocated `File` objects even when `fileName.trim()` was blank. In `exists()`, `context.contentResolver.query(...)` evaluated `it.count > 0` which requires a full cursor scan, and called `GalleryTarget.relativePath(fileName)` twice.
- **Fix:** Added early `val trimmed = fileName.trim(); if (trimmed.isEmpty()) return` guard before `File` allocation. In `exists()`, computed `relPath` once and switched cursor existence check to `it.moveToFirst()` for $O(1)$ fast evaluation.

### Pass 835 — `:feature-l` (`SavedL_Albums.kt`)
- **Finding:** In `add()` and `addAndPicsDetails()`, `item.id.toLongOrNull()` was computed repeatedly. In `addAndPicsDetails()`, empty `picsDetails` lists triggered unnecessary JSON serialization into cache. In `remove()`, blank item IDs were not guarded.
- **Fix:** Stored parsed `albumId = item.id.toLongOrNull()` once, added `if (item.id.isBlank()) return` in `remove()`, only put pictures in cache when `picsDetails.isNotEmpty()`, and added `contains(id: String): Boolean` helper.

### Pass 836 — `:feature-l` (`SavedL_Collection.kt`)
- **Finding:** In `remove(item: PicsDetails, ...)`, `listOfNotNull(...) + (item.thumbnails?.mapNotNull ... ?: emptyList())` allocated three separate lists and performed list concatenation. In `addAll()` and `removeAll()`, `distinctBy` was unconditionally run even for 1-element collections. Empty items in `beginAddManyToCollection()`, `addAll()`, and `removeAll()` did not exit early.
- **Fix:** Pre-sized a single `ArrayList<String>(4)` collecting identifiers directly in `remove()`. Added early return on empty item lists, skipped `distinctBy` when `items.size <= 1`, and added early blank guard to URL removal.

### Pass 837 — `:feature-l` (`SavedL_Likes.kt`)
- **Finding:** `add(item)` did not validate if both `url_to_original` and `url_to_video` were blank before launching coroutines. `remove(url)` launched an IO coroutine even for blank URLs.
- **Fix:** Added early return with user feedback if media URLs are blank, and added `if (url.isBlank()) return` in `remove()`.

### Pass 838 — `:feature-r` (`DownloadRed.kt`)
- **Finding:** `refreshDownloadList()` allocated `infoFiles` and `mp4Files` lists even when `r_cache_download` did not exist or was empty. `downloadItem()` and `delete()` did not guard against blank IDs or userNames before queuing or deleting.
- **Fix:** Added fast return if `rootDir` does not exist or is not a directory. Emitted empty lists immediately when no files are found without sorting. Added blank guards to `downloadItem()` and `delete()`.

### Pass 839 — `:feature-r` (`R_Saved_Likes.kt`)
- **Finding:** In `remove(item: GifsInfo)`, blank `item.id` was not checked before launching IO coroutines. In `refresh()`, empty likes list still executed `sanitizeGifsInfoList()` and list equality checks.
- **Fix:** Added `if (item.id.isBlank()) return` in `remove()`, added early return `if (current.isEmpty()) return@launch` in `refresh()`, and introduced `contains(id: String): Boolean` for fast lookups.

### Pass 840 — `:feature-r` (`R_Saved_NichesCaches.kt`)
- **Finding:** Every access to `cacheFile()` allocated a new `File` object. `refreshIfStale()` performed file I/O (`timeRefresh()`) even when `isDownloading` was already true. `readFromDisk()` attempted reading 0-byte cache files.
- **Fix:** Cached `private val cacheFile = File(AppPath.r_nichesCache, CACHE_FILE_NAME)`. Checked `if (isDownloading) return` before calling `timeRefresh()`. Added `cacheFile.length() == 0L` guard in `readFromDisk()`.
