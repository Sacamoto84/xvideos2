## 1. Контекст и цели прохода (Код-ревью библиотеки :core)

Проведён комплексный аудит кодовой базы библиотечного модуля `:core`, предоставляющего фундаментальные UI-компоненты, слой хранения данных и вспомогательные утилиты для всех фичевых модулей проекта (`:feature-r`, `:feature-l`, `:feature-x` и `:app`).

**Ключевые цели:**
1. **Искоренение устаревших зависимостей**: Полный отказ от устаревшего стороннего пакета `com.composeunstyled.Text` в пользу `androidx.compose.material3.Text`.
2. **Оптимизация производительности списков и Compose-компонентов**: Устранение аллокаций `listOf(Unit)` в `LazyVerticalGrid`, выделение ячейки `CollectionGridCard` с мемоизацией колбэков, перевод `LinearProgressIndicator` на неблокирующий лямбда-оверлоад.
3. **Устранение дублирования кода**: Замена локальной ad-hoc функции `formatBytes1` на каноническую утилиту проекта `formatBytes`.
4. **Надёжность состояния диалогов**: Сброс внутреннего текстового состояния диалога `DaialogNewCollection` при изменении флага видимости.

## 2. Выявленные проблемы и решения

### 1. Оптимизация и модернизация [`CollectionsGrid.kt`](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/collectionDB/ui/CollectionsGrid.kt)
- **Устаревший `com.composeunstyled.Text`**: Компонент использовал устаревший сторонний `Text`. Заменён на стандартный `androidx.compose.material3.Text`.
- **Аллокация фиктивного списка `items(listOf(Unit))`**: Для добавления кнопки «+» в конец сетки коллекций использовался вызов `items(listOf(Unit))`. При каждой рекомпозиции сетки выделялся новый объект списка в памяти без стабильного ключа. Заменено на каноничный `item(key = "add_new_collection")`.
- **Вынос ячейки `CollectionGridCard`**: Логика отрисовки строки коллекции вынесена в отдельный компонент `CollectionGridCard` с мемоизацией лямбд клика `val handleClick = remember(collection.name, onClick)` и долгого нажатия `val handleLongClick = remember(collection.name, onCollectionLongClick)`.
- **Защита от отображения `">null"`**: При `selectedCollection == null` (дефолтный просмотр всех коллекций) запасной заголовок тулбара мог рендерить строку `">null"`. Добавлена проверка `if (headerText.isNotEmpty())`.

### 2. Сброс состояния ввода в [`DaialogNewCollection.kt`](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/collectionDB/ui/DaialogNewCollection.kt)
- **Проблема**: Поле ввода `var text by remember { mutableStateOf("") }` сохраняло предыдущий введённый текст при повторном открытии диалога.
- **Решение**: Добавлен ключ видимости: `var text by remember(visible) { mutableStateOf("") }`. Теперь при каждом повторном показе диалога поле ввода гарантированно очищается. Устранён избыточный параметр лямбды в `@Preview`.

### 3. Лямбда-оверлоад индикатора прогресса в [`DownloadIndicator.kt`](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/ui/atom/DownloadIndicator.kt)
- **Проблема**: Использовался устаревающий перегруженный метод `LinearProgressIndicator(progress: Float, ...)`, требующий рекомпозиции всего родительского контейнера при каждом изменении процента скачивания.
- **Решение**: Переведено на современный неблокирующий лямбда-оверлоад Material 3: `LinearProgressIndicator(progress = { percentDownload }, ...)`.

### 4. Унификация форматирования байтов и миграция в [`UrlImage.kt`](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/coil/UrlImage.kt)
- **Дублирование `formatBytes1`**: В `UrlImage.kt` находилась локальная ad-hoc реализация `formatBytes1` с пробелами в суффиксах (`"$bytes "`, `" K"`). В `:core` уже существует стандартизированная и протестированная функция `com.client.xvideos.common.util.formatBytes`.
- **Решение**: Удалена функция `formatBytes1`, вызовы в `ProgressText` переведены на каноничный `formatBytes`, удалён неиспользуемый импорт `kotlin.math.roundToInt`.
- **Миграция `Text`**: Заменён `com.composeunstyled.Text` на `androidx.compose.material3.Text`.

### 5. Очистка устаревших подавлений и импортов
- В [`CollectionDB.kt`](file:///g:/xvideos2/core/src/main/java/com/client/xvideos/common/collectionDB/CollectionDB.kt) удалена избыточная аннотация `@Suppress("UNCHECKED_CAST")` над `readAllCollections()`.
- В [`R_Screen_CollectionTab.kt`](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_CollectionTab.kt) удалён неиспользуемый импорт `com.composeunstyled.Text`.
