Калькулятор принимает не больше 15 цифр: и буфер кода `enteredPinDigits`, и

### T2 — Веб-сервер: сервис `dataSync` не обрабатывает предел времени. Средняя.

[WebServerService.kt:21](../core/src/main/java/com/client/xvideos/common/webserver/WebServerService.kt:21) ·
[WebServerService.kt:61](../core/src/main/java/com/client/xvideos/common/webserver/WebServerService.kt:61)

`targetSdk = 37`. Начиная с Android 15 foreground-сервису типа `dataSync`
отводится 6 часов в сутки (суммарно, пока приложение не на экране). По
истечении система зовёт `Service.onTimeout(int, int)` и ждёт `stopSelf()`
несколько секунд; сервис, который не остановился, система завершает
исключением — это падение процесса. `WebServerService` метод не
переопределяет.

Вторая сторона того же: сбой `startForeground` (в том числе «лимит уже
исчерпан») ловится в `try/catch` и только пишется в лог. Сервис продолжает
запуск без foreground-статуса; для сервиса, запущенного через
`startForegroundService`, это тоже кончается исключением системы через
несколько секунд.

Сценарий: трансляция на ПК дольше шести часов за сутки при свёрнутом
приложении.

Чего нет: вывод по документации Android 15, на устройстве не воспроизведено.
P2P-сервис той же природы не смотрел — P2P заморожен.
