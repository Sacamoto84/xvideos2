### C1 — Повтор после сбоя первой страницы картинок загружает только её. Средняя.

[feature-l/.../net/AlbumPicsDetails.kt:376](../feature-l/src/main/java/com/client/xvideos/l/net/AlbumPicsDetails.kt:376)

Если первая страница картинок не загрузилась, `contentUrls()` выходит сразу
(строки 255–260), в `failedPages` остаётся одна запись. `retryFailedPages()`
повторяет только сбойные страницы: страница 1 загружается, `failedPages` пуст,
`finally` ставит `percentLoad = 1f`. Страницы 2..N не запрашиваются никогда.

Альбом показывает первую порцию картинок как полный. `AlbumInfo.retryFailedPages()`
тут же кладёт этот набор в кэш бандлов (срок — 7 дней), и следующие открытия до
ручного обновления показывают усечённый альбом без признаков ошибки.

### C2 — Повтор во время идущей загрузки кэширует неполный альбом. Средняя.

[feature-l/.../net/AlbumPicsDetails.kt:389](../feature-l/src/main/java/com/client/xvideos/l/net/AlbumPicsDetails.kt:389)

Кнопка «Повторить страницы» проверяет только `isRetryingFailedPages`
([LAlbumNetworkIssuePanel.kt:131](../feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbum/LAlbumNetworkIssuePanel.kt:131)),
то есть активна, пока основная последовательная загрузка ещё идёт. Страница 3
из 40 упала, пользователь жмёт повтор: страница 3 загружена, `failedPages`
пуст, `finally` ставит `percentLoad = 1f`, `bundleSnapshotOrNull()` отдаёт
снимок из загруженных к этому моменту страниц, и

Если пользователь ушёл с экрана до конца загрузки или позже упала другая
страница, полный снимок кэш не перезаписывает — следующее открытие показывает
часть альбома как полный. Индикатор прогресса при этом прыгает на 100% и
обратно.

[feature-l/.../screenAlbumList/ScreenAlbumListSM.kt:236](../feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbumList/ScreenAlbumListSM.kt:236)
