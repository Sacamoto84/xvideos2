### C1 — Завершение иерархической навигации BackHandler в Saved-экранах Red. Средняя.

[feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_Saved_LikesTab.kt:60-66](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_Saved_LikesTab.kt#L60-L66)  
[feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_CreatorsTab.kt:100-112](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_CreatorsTab.kt#L100-L112)  
[feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/savedNiche/SavedNichesTab.kt:75-87](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/savedNiche/SavedNichesTab.kt#L75-L87)  
[feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_CollectionTab.kt:98-112](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/saved/tab/R_Screen_CollectionTab.kt#L98-L112)

1. В `R_Screen_Saved_LikesTab.kt` отсутствовал `BackHandler`. При прокрутке сохранённых GIF-анимаций вниз (`vm.likedHost.state.firstVisibleItemIndex > 0`) нажатие системной кнопки «Назад» не возвращало к началу списка, а сразу приводило к смене родительской вкладки на ленту GIF (`ScreenRedExplorer`).
2. В `R_Screen_CreatorsTab.kt` обрабатывалось закрытие диалога удаления автора (`itemPendingDelete != null`), но при закрытом диалоге и прокрученном списке авторов (`state.firstVisibleItemIndex > 0`) нажатие «Назад» не скроллило список к началу, а сразу переключало таб на `LikesTab`.
3. В `SavedNichesTab.kt` аналогично: при `itemPendingDelete == null && state.firstVisibleItemIndex > 0` отсутствовал обработчик скролла к началу списка сохранённых групп.
4. В `R_Screen_CollectionTab.kt` при закрытых диалогах и отсутствии открытой коллекции (`selectedCollection == null`) прокрученная сетка коллекций (`vm.gridState.firstVisibleItemIndex > 0`) не возвращалась к началу по жесту «Назад».

**Решение:**
- В `R_Screen_Saved_LikesTab.kt` подключить `BackHandler(enabled = vm.likedHost.state.firstVisibleItemIndex > 0) { vm.likedHost.gotoUp() }`.
- В `R_Screen_CreatorsTab.kt` и `SavedNichesTab.kt` добавить второй уровень `BackHandler(enabled = itemPendingDelete == null && state.firstVisibleItemIndex > 0) { scope.launch { state.animateScrollToItem(0) } }`.
- В `R_Screen_CollectionTab.kt` добавить `BackHandler` для `vm.gridState.firstVisibleItemIndex > 0` при отсутствии открытых диалогов и коллекций.

### C2 — Иерархический BackHandler со скроллом к началу в основных лентах Red. Средняя.

[feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/gifs/R_ScreenGifsTab.kt:100-106](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/gifs/R_ScreenGifsTab.kt#L100-L106)  
[feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/niches/R_ScreenNichesTab.kt:160-168](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/explorer/tab/niches/R_ScreenNichesTab.kt#L160-L168)

1. В главной ленте GIF-анимаций (`R_ScreenGifsTab`, таб 0) при прокрутке ленты вниз (`vm.lazyHost.state.firstVisibleItemIndex > 0`) отсутствовал `BackHandler`. Нажатие «Назад» сразу вызывало системное сворачивание приложения или выход из навигатора вместо возврата к первой позиции ленты (поведение, аналогичное кнопке `ButtonUp`).
2. Во вкладке категорий/ниш (`R_ScreenNichesTab`, таб 2) при прокрученном списке (`listState.firstVisibleItemIndex > 0`) нажатие «Назад» сразу переключало родительский контейнер на таб 0, минуя плавный возврат к верху списка.

**Решение:**
- В `R_ScreenGifsTab.kt` внедрить `BackHandler(enabled = vm.lazyHost.state.firstVisibleItemIndex > 0) { vm.lazyHost.gotoUp() }`.
- В `R_ScreenNichesTab.kt` внедрить `BackHandler(enabled = listState.firstVisibleItemIndex > 0)` с вызовом `coroutineScope.launch { listState.scrollToItem(0); navigationState.resetNichesScrollPosition() }`.

### C3 — Иерархический BackHandler и проброс gridState в дашбордах и истории X. Средняя.

[feature-x/src/main/java/com/client/xvideos/x/screens/history/ScreenXHistory.kt:150-165, 230](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/history/ScreenXHistory.kt#L150-L165)  
[feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/DashboardsPaginatedListScreen.kt:102-110, 150, 195](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/DashboardsPaginatedListScreen.kt#L102-L110)

1. В `ScreenXHistory.kt` список `LazyVerticalGrid` не имел явно переданного `state`. При наличии обработчиков диалогов (`isAnyDialogOpen`) и режима выбора (`isSelectionMode`) отсутствовал обработчик возврата к первому элементу. При прокрученной истории нажатие «Назад» сразу закрывало экран истории или переключало главный таб.
2. В `DashboardsPaginatedListScreen.kt` сетка `LazyVerticalGrid` создавала локальный `state = rememberLazyGridState(...)` внутри `DashboardsPaginatedListContent` без возможности перехвата скролла. Если пользователь пролистал видео на любой странице дашборда вниз, нажатие «Назад» на нулевой странице сразу закрывало экран, минуя возврат к шапке страницы.

**Решение:**
- В `ScreenXHistory.kt` вынести `gridState = rememberLazyGridState()`, связать его с `LazyVerticalGrid(state = gridState)` и добавить 3-й приоритет: `BackHandler(enabled = !isAnyDialogOpen && !isSelectionMode && gridState.firstVisibleItemIndex > 0) { scope.launch { gridState.animateScrollToItem(0) } }`.
- В `DashboardsPaginatedListScreen.kt` вынести `gridState` наружу в родительский Composable, добавить `BackHandler(enabled = videoItems.isNotEmpty() && gridState.firstVisibleItemIndex > 0) { scope.launch { gridState.animateScrollToItem(0) } }` и передавать `gridState` в `DashboardsPaginatedListContent`.
