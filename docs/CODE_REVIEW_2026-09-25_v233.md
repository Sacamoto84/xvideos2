## Summary of Passes

### Pass 721 (`:core` — `toMinSec.kt`)
- Eliminated `String.format(Locale.US, "%02d:%02d", minutes, seconds)` overhead (format string parsing, vararg array allocations, and integer autoboxing) on every video timestamp and player progress update by replacing it with direct digit checks (`if (minutes < 10) "0$minutes" else "$minutes"` and `if (seconds < 10) "0$seconds" else "$seconds"`).
- Removed unused `java.util.Locale` import.

### Pass 722 (`:core` — `toMD5.kt`)
- Optimized `String.toMD5()`: replaced 16 repeated `"%02x".format(it)` calls inside `joinToString` (which allocated formatters, vararg arrays, strings, and boxing for every byte) with a static 16-element hex character lookup table writing directly into a 32-element `CharArray`.
- Accelerates all callers across ROM/RAM cache keys, request hashing, and checksum calculations.

### Pass 723 (`:core` — `formatBytes.kt` & `formatSpeed.kt`)
- Hoisted precomputed constants for byte boundaries (`ONE_KB = 1024L`, `ONE_MB = 1024L * 1024L`, `ONE_GB = 1024L * 1024L * 1024L` and corresponding double factors) in `formatBytes.kt` and `formatSpeed.kt` to avoid repeated floating-point arithmetic at runtime.

### Pass 724 (`:core` — `M3U8Helper.kt`)
- Hoisted static request headers `REDGIFS_REQUEST_HEADERS` and `EMPTY_M3U8_DATA` to avoid repeated `mapOf(...)` and object allocations per M3U8 network request.
- Replaced `m3u8Content.lines()` (which created a full in-memory `List<String>`) with lazy sequence iteration `m3u8Content.lineSequence()`.
- Optimized `formatResolution` by replacing `resolution.split("x")` with direct `resolution.substringAfter('x', "")`.

### Pass 725 (`:core` — `Utils.kt` in `kdownloader`)
- In `getUniqueId`, replaced `string.toByteArray(charset("UTF-8"))` with `string.toByteArray(Charsets.UTF_8)` to avoid charset lookups.
- Replaced per-byte `Integer.toHexString` string allocations with direct char array hex formatting matching standard hex lowercase output.
- Cleaned up unused imports `UnsupportedEncodingException` and `kotlin.experimental.and`.

### Pass 726 (`:feature-x` — `parserScreenTags.kt` & `CountryFlag.kt`)
- In `parserScreenTags.kt`, hoisted `EMPTY_MODEL_SCREEN_TAG`, pre-allocated the result list with `ArrayList<ItemsX>(videos.size)`, and replaced intermediate list allocation in pagination max resolution (`.mapNotNull { }.maxOrNull()`) with single-pass `.fold(1) { acc, el -> maxOf(...) }`.
- In `CountryFlag.kt`, replaced `replace("flag-", "")` and multiple string/array allocations for surrogate pairs with single-pass `removePrefix` and `Character.toChars(codePoint, chars, offset)` into a single `CharArray(4)`.

### Pass 727 (`:feature-r` — `R_Saved_Likes.kt`, `R_Saved_Creator.kt`, `R_Saved_Niches.kt`)
