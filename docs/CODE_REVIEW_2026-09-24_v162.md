## 1. Контекст и цели проходов (2 код-ревью)

В рамках непрерывного аудита качества кодовой базы выполнены два взаимосвязанных прохода:
- **Проход 188**: Очистка мертвого кода, устаревших прототипов и остаточных Hilt-биндингов (`:feature-r`). Удаление заброшенных классов раннего прототипа экрана `ScreenRedTopThisWeek` (100% закомментированный код экрана, неиспользуемый ScreenModel с DI-модулем, отладочный TikTok-пейджер, локальный ErrorState и Enum VisibleType) и удаление закомментированного мусора в `ProfileInfo1.kt`.
- **Проход 189**: Оптимизация производительности Compose-рендеринга и предотвращение избыточных рекомпозиций в `:feature-x`. Мемоизация колбэков видеороликов и навигации в `ScreenXDashBoards` и `DashboardControlsRow`, вынос ячейки `TagGridCell` с фиксацией лямбд открытия плеера в `TagsPaginatedListScreen`, а также устранение фиктивного параметра `isCurrentPage`, вызывавшего паразитные рекомпозиции кэшированных страниц при горизонтальном скролле пейджеров.

## 2. Выявленные проблемы и решения

### Проход 188: Очистка мертвого кода в `:feature-r`

1. **Удаление заброшенного прототипа `ScreenRedTopThisWeek` и зависимостей**:
   - **Проблема**: В пакете `com.client.xvideos.r.ui.top_this_week` находился файл [`ScreenRedTopThisWeek.kt`](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/top_this_week/ScreenRedTopThisWeek.kt), полностью состоящий из 147 строк закомментированного кода. Рядом находился [`ScreenRedTopThisWeekSM.kt`](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/top_this_week/ScreenRedTopThisWeekSM.kt) с Hilt-модулем `ScreenModuleRedTopThisWeekBlock`, нигде более не используемый `TikTokRow1.kt` (116 строк), локальный компонент ошибки `ErrorState.kt` (46 строк) и enum `VisibleType.kt`. Настоящий активный экран гифок/топа уже давно реализован в `R_ScreenGifsTab.kt`.
   - **Решение**: Удалены 5 полностью неиспользуемых файлов (суммарно ~400 строк мертвого кода).
2. **Очистка [`ProfileInfo1.kt`](file:///g:/xvideos2/feature-r/src/main/java/com/client/xvideos/r/ui/top_this_week/ProfileInfo1.kt)**:
   - Удалён блок закомментированного кода (10 строк) в теле компонента `ProfileInfo1`.

### Проход 189: Оптимизация производительности Compose в `:feature-x`

1. **Стабилизация колбэков страницы дашбордов в [`ScreenXDashBoards.kt`](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/ScreenXDashBoards.kt)**:
   - **Проблема**: В теле `HorizontalPager` для каждого `pageIndex` инлайн создавались 6 анонимных лямбд: `openVideoPlayer`, `isFavorite`, `onFavoriteAdd`, `onFavoriteRemove`, `onDownload`, `onSaveToGallery`. При каждой рекомпозиции `ScreenXDashBoards` инстанциировались новые объекты лямбд.
   - **Решение**: Все 6 колбэков мемоизированы на уровне экрана через `remember(vm, navigator)` и `remember(vm)`.
2. **Устранение паразитных рекомпозиций через `isCurrentPage` в [`DashboardsPaginatedListScreen.kt`](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/DashboardsPaginatedListScreen.kt) и [`TagsPaginatedListScreen.kt`](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/tags/atom/TagsPaginatedListScreen.kt)**:
   - **Проблема**: В `ScreenXDashBoards` в `DashboardsPaginatedListScreen` передавалось `isCurrentPage = vm.mainTab == 0 && vm.pagerState.currentPage == pageIndex`. При этом сам экран `DashboardsPaginatedListScreen` вообще не использовал параметр `isCurrentPage`. Однако смена `currentPage` при свайпе приводила к передаче изменённого булевого флага и инвалидировала кэш соседних страниц в `beyondViewportPageCount`. Аналогичная ситуация наблюдалась в `ScreenTags.kt` и `TagsPaginatedListScreen.kt`.
   - **Решение**: Параметр `isCurrentPage` удалён из сигнатур и вызовов обоих экранов. Теперь предзагруженные соседние страницы не рекомпонуются при перелистывании.
3. **Мемоизация навигации страниц в [`DashboardControlsRow.kt`](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/dashboards/bottomBar/DashboardControlsRow.kt)**:
   - Инлайн-лямбда запуска корутины переключения страниц обёрнута в `val handleChange = remember(job, onChange) { ... }`, предотвращая лишние рекомпозиции компонента `BottomListDashBoardNavigationButtons2`.
4. **Вынос ячейки `TagGridCell` в [`TagsPaginatedListScreen.kt`](file:///g:/xvideos2/feature-x/src/main/java/com/client/xvideos/x/screens/tags/atom/TagsPaginatedListScreen.kt)**:
   - Внутренний блок рендеринга ячейки видео вынесен в `@Composable TagGridCell` со стабильным `val handleOpen = remember(cell, onOpenVideo) { { onOpenVideo(cell) } }`, устраняя постоянные аллокации лямбд внутри `forEach`.
