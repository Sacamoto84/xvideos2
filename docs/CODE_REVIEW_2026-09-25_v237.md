## Summary of Passes (753–760)

### Pass 753 — `:core` (`FileDB.kt`)
- **Finding:** `FileDB` constructed `File(dirPath)` on every `refresh()`, `insert()`, `delete()`, `clear()`, and `cleanupTempFiles()`, and constructed `".$extension"` repeatedly. Furthermore, `refresh()` and `clear()` invoked `cleanupTempFiles()` (which called `dir.listFiles()`) immediately before calling `dir.listFiles()` a second time to filter `.extension` records, doubling native filesystem directory enumeration syscalls.
- **Fix:** Cached `private val dir = File(dirPath)` and `private val dotExtension = ".$extension"` as instance fields. Merged `.tmp` orphan deletion and `.extension` record filtering into a single `dir.listFiles()` pass in `refresh()` and `clear()`, and replaced `.sortedByDescending` list copying with in-place `files.sortByDescending { it.lastModified() }`.

### Pass 754 — `:core` (`CollectionDB.kt`)
- **Finding:** `CollectionDB` constructed `File(path)` on every operation and, in `readAllCollections()`, invoked `cleanupTempFiles(root)` (enumerating `root.listFiles()` and each subdirectory's `dir.listFiles()`) immediately prior to enumerating `root.listFiles()` and every `dir.listFiles()` a second time to parse `.collection` items.
- **Fix:** Cached `private val rootDir = File(path)` at the instance level and unified `.tmp` cleanup with `.collection` file collection inside a single per-directory `dir.listFiles()` pass via `loadCollectionDir(dir)`, cutting native directory enumerations in half across all user collections.

### Pass 755 — `:core` (`LocalWebServer.kt` & `VideoDiskCacheCleaner.kt`)
- **Finding:** `LocalWebServer`'s root `/` handler opened the APK asset stream `assets.open("web/index.html")` and allocated `ContentType.Text.Html.withCharset(Charsets.UTF_8)` on every root page load. `VideoDiskCacheCleaner` allocated boxed `List<String>` collections and iterator objects for two fixed-size pairs of legacy cache names.
- **Fix:** Hoisted `private val HTML_UTF8 = ContentType.Text.Html.withCharset(Charsets.UTF_8)` and cached `web/index.html` bytes in `private val cachedIndexHtml = AtomicReference<ByteArray?>(null)` in `LocalWebServer` (preserving immutable global property invariants enforced by `GlobalStateTest`). Replaced `listOf` with `arrayOf` and cached `appContext.cacheDir` in `VideoDiskCacheCleaner`.

### Pass 756 — `:feature-x` (`parserListVideo.kt`)
- **Finding:** For every `div.frame-block` card (~27 cards per page), `parserListVideo` executed `block.selectFirst("p.title a")` twice and `block.selectFirst("p.metadata...")` three times, causing 3 redundant CSS selector DOM subtree traversals per card (~81 extra DOM queries per page). Additionally, `extractViews()` wrapped `VIEWS_TOKEN_REGEX.findAll(metadata)` in `.map { }.lastOrNull { }` sequence adapters.
- **Fix:** Pre-sized `ArrayList<ItemsX>(videoBlocks.size)`, cached `titleAnchor = block.selectFirst("p.title a")` and `metadataEl = block.selectFirst("p.metadata")` once per video block, and replaced the `Sequence` chain in `extractViews()` with a direct loop over `VIEWS_TOKEN_REGEX.findAll(metadata)`.

### Pass 757 — `:feature-l` (`getFavoritesByDatePicture.kt` & `getFavoritesByDatePictureSet.kt`)
- **Finding:** Both `getFavoritesByDatePicture` and `getFavoritesByDatePictureSet` interpolated and executed `.trimIndent()` on 60–90 line GraphQL query strings on every pagination call, despite there being only two static query shapes (`hasUserId = true` and `hasUserId = false`).
- **Fix:** Precomputed `FAVORITES_PICTURE_WITH_USER_QUERY` / `FAVORITES_PICTURE_NO_USER_QUERY` and `FAVORITES_SET_WITH_USER_QUERY` / `FAVORITES_SET_NO_USER_QUERY` as top-level constants.

### Pass 758 — `:feature-l` (`getFavoriteAdd.kt` & `getFavoriteRemove.kt`)
- **Finding:** `getFavoriteAdd` and `getFavoriteRemove` ran `.trimIndent()` on static multi-line GraphQL mutation definitions on every like/unlike action.
- **Fix:** Hoisted `FAVORITE_ADD_QUERY` and `FAVORITE_REMOVE_QUERY` to top-level constants.

### Pass 759 — `:feature-r` (`ApiClient.kt`)
- **Finding:** Every authenticated RedGifs API request allocated a new `"Bearer $it"` string and a nested `headers { append(...) }` lambda builder, and `ensureToken()` / `refreshToken()` allocated `Result.success(Unit)` on every request.
- **Fix:** Precomputed and cached `internal val bearerHeaderRef = AtomicReference<String?>(null)` (`"Bearer $token"`) in `loginLocked()` (and cleared it on token invalidation in `refreshToken`), hoisted `private val SUCCESS_UNIT = Result.success(Unit)`, and replaced nested `headers { append(...) }` blocks with direct `headers.append(HttpHeaders.Authorization, authHeader)`.

### Pass 760 — `:core` (`toPrettyCount.kt`)
- **Finding:** `Long.toPrettyCountInt()` invoked `String.format(Locale.US, "%.0fK", value)` (which parses the format pattern and constructs a `Formatter` on every call) solely to round a `Double` to the nearest integer with a unit suffix. All four `toPrettyCount*` functions also duplicated the `Long.MIN_VALUE`-safe `abs` check and `"$absValue"` string template for values `< 1_000`.
- **Fix:** Extracted `private fun Long.absSafe(): Long`, replaced `"$absValue"` with `absValue.toString()`, and replaced `String.format(Locale.US, "%.0f...", value)` in `toPrettyCountInt()` with direct `roundToLong()` arithmetic.
