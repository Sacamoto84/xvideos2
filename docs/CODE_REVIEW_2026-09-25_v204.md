1. **[`AlbumListFilterSize.kt`](file:///g:/xvideos2/feature-l/src/main/java/com/client/xvideos/l/ui/screens/screenAlbumList/molecule/filter/atom/AlbumListFilterSize.kt)**:
   - **Сигнатура Composable**: добавлен параметр `modifier: Modifier = Modifier`, размещённый перед `onChange` для сохранения синтаксиса trailing lambda на вызывающей стороне.
