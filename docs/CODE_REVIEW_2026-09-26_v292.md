# Code Review & Architecture Refactoring Report — Batch 76 (v292)
**Date:** 2026-09-26  
**Scope:** Passes 1193–1200 (`:core`)

---

## 1. Executive Summary

Batch 76 (v292) conducts an architectural review of `:core` non-UI networking, DNS-over-HTTPS (DoH), player state modeling, formatting utilities, and local web server runtime components. It introduces DNS record classification and type filtering (`hasOnlyIpv4`, `hasIpv6`, `filterByType`, `isCname`) in `DohModels.kt`, preset detection, name registries, and nullable lookups (`isPreset`, `allNames`, `fromNameOrNull`) in `DohProvider.kt`, extreme speed limits and option listings (`isFastest`, `isSlowest`, `allDisplayNames`, `allOptions`) in `enumPlayerSpeed.kt`, playback speed predicates and config mutation builders (`isNormalSpeed`, `hasCustomSpeed`, `withFitMode`, `withUrl`) in `PlayerPlaybackConfig.kt`, formatted byte validation and bit-speed calculations (`isValidByteString`, `formatAsBitsPerSec`) in `formatBytes.kt` and `formatSpeed.kt`, hour-aware duration formatters and safe second parsers (`toHoursMinSec`, `toSecondsOrZero`) in `toMinSec.kt`, and state reset operations with online/error status predicates (`hasError`, `isOnline`, `reset`) in `WebServerState.kt`.
