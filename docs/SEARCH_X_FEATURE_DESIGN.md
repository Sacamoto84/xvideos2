# Архитектурный дизайн вкладки Поиска (Search Tab) в разделе X

## 1. Резюме согласованных требований (Understanding Summary)
* **Цель**: Добавить полноценный экран поиска в качестве третьей вкладки нижней панели раздела X (`ScreenXDashBoards`), реализующий динамическую подгрузку подсказок по аналогии с сайтом `https://www.xv-ru.com/`.
* **Порядок вкладок снизу**: `[Дашборды (0)]`, `[Сохранённое (1)]`, `[Поиск (2)]`.
* **UX/Поведение**:
  * Двухфазный экран в пределах вкладки:
    * *Фаза ввода*: строка поиска + локальная история запросов (до ввода) / список живых подсказок (во время ввода);
    * *Фаза результатов*: двухколоночная пагинированная сетка видеороликов (`LazyVerticalGrid`).
  * Переход по клику:
    * Клик по фразе/тегу (`Keyword`) или Enter -> запуск поиска видео и показ результатов в текущей вкладке;
    * Клик по карточке модели/порнозвезды (`Pornstar`) -> открытие профиля автора (`ScreenX_Channel(slug, isModel = true)`);
    * Клик по карточке студии/канала (`Channel`) -> открытие профиля канала (`ScreenX_Channel(slug, isModel = false)`).
  * Пагинация результатов: верхний ярус нижней панели Scaffold над табами отображает `BottomListDashBoardNavigationButtons2` со стрелками и выбором страницы при активной фазе результатов.

## 2. Зафиксированные допущения (Assumptions)
* **Debounce**: Задержка 350 мс перед отправкой запроса к эндпоинту подсказок `/search-suggest/<query>`.
* **Формат API**: Поддержка как вложенной схемы `{"result": true, "data": {"keywords": [...], "pornstar": [...], "channel": [...]}}`, так и плоской схемы JSON.
* **История поиска**: Локальный JSON-файл на устройстве с ограничением в 30 последних уникальных запросов (LIFO).
* **BackHandler**:
  * В режиме результатов нажатие «Назад» возвращает к строке поиска и подсказкам/истории;
  * При непустой строке поиска «Назад» очищает ввод;
  * При пустом поиске «Назад» переключает на первый таб (Дашборды).

## 3. Журнал решений (Decision Log)
* **Выделенная ScreenModel (`ScreenXSearchSM`)**:
  * *Альтернативы*: Монолитный `ScreenXDashBoardsScreenModel`, изолированный вложенный Scaffold.
  * *Причина*: Соблюдение SRP, изоляция логики поиска от дашбордов и сохранённого, лёгкость тестирования.
* **Двухфазный экран в одной вкладке**:
  * *Альтернативы*: Отдельный экран результатов через Voyager push, живая фильтрация сетки без подтверждения.
  * *Причина*: Стандартный удобный UX мобильного поиска, отсутствие лишних пересозданий экрана.
* **Прямой переход в профиль при клике на автора/канал**:
  * *Альтернативы*: Подстановка имени в строку поиска.
  * *Причина*: Более глубокая интеграция с уже реализованной фичей профилей авторов и каналов в X.

## 4. Архитектура и компоненты

### 4.1. Сетевой слой и модели данных
* **Модели (`feature-x/src/main/java/com/client/xvideos/x/search/model/searchModel.kt`)**:
  * `Keyword`: ключевые слова/фразы (`N`, `R`).
  * `Pornstar`: модели (`N`, `F`, `MV`, `P`, `RF`, `T`).
  * `Channel`: каналы (`N`, `F`, `CPV`, `P`, `RF`, `T`).
  * `SearchResult`: общий контейнер с безопасным разбором поля `data`.
* **Сетевые функции**:
  * `getSearchResults(query: String)`: запрос к `$urlStart/search-suggest/<encoded_query>`.
  * `loadSearchVideos(query: String, page: Int)`: запрос к `$urlStart/?k=<query>&p=<page>` через `readHtmlFromURLDirect` (или `readHtmlFromURLWebView`), парсинг через `parserListVideo` и `parseLastPage`.

### 4.2. Хранилище истории поиска
* **`XSearchHistoryStore`**:
  * Управляет сохранением и удалением недавних поисковых запросов в локальный файл.
  * Реактивный `Flow<List<String>>`.

### 4.3. ScreenModel (`ScreenXSearchSM`)
* Управляет:
  * Потоком ввода `query` с `debounce(350)` и `collectLatest`;
  * Режимом UI: `SearchUiMode { HISTORY, SUGGESTIONS, RESULTS }`;
  * Подгрузкой подсказок (`isSuggestLoading`, `suggestions`);
  * Подгрузкой видео (`isVideoLoading`, `videoItems`, `currentPage`, `maxPages`);
  * Историей поиска.

### 4.4. UI-компоненты
* **`ScreenXSearchContent`**: Главный контейнер вкладки поиска.
* **`SearchTopBar`**: Строка поиска с кнопками «Назад», «Очистить» и прогресс-баром.
* **`SearchHistorySection`**: Список недавних запросов с удалением.
* **`SearchSuggestionsSection`**: Сгруппированный список фраз, карточек авторов и каналов.
* **`SearchResultsSection`**: Сетка `UrlVideoImageAndLongClickX` с поддержкой избранного и скачивания.
* **Интеграция в `ScreenXDashBoards`**:
  * Добавление таба `SEARCH = 2`;
  * Вывод `BottomListDashBoardNavigationButtons2` в нижней панели при `mainTab == SEARCH && uiMode == RESULTS`.
